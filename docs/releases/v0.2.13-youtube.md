# SnowDown v0.2.13 YouTube 修订

新增 YouTube 公开视频与 Shorts 的完整解析下载验证，内置浏览器插件 v0.1.13。

桌面延长实际解析与本机联动的超时，并在短期缓存中保留已经解析出的 YouTube 媒体，点击下载时复用已解析结果，减少重复播放器处理。原登录、设置与下载内容继续使用原有数据目录。

按用户要求，桌面版本号仍为 **v0.2.13**。原 v0.2.13 标签和附件保留，此次另提供文件名带 `youtube` 的修订安装器及免安装包。已安装 v0.2.13 不会因相同版本号弹出自动升级提示，请手动安装修订包。修订源码位于 `extension-v0.1.13` 标签，验证记录见同批插件发布附件。

用户提供的 Shorts 已通过实际桌面解析、下载及输出音视频解码验证。部分视频仍可能要求官方登录或验证，或受到地区、账号及内容格式限制。

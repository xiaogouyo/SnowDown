SnowDown 首个 Windows 桌面测试版本。本机解析与下载B站视频，文件保存在自己的电脑中。

## 下载

- **安装版**：下载 `SnowDown_0.1.0_x64-setup.exe` 后运行安装。
- **免安装版**：下载 `SnowDown_0.1.0_Windows_x64_portable.zip`，完整解压后运行 `SnowDown.exe`，保留 `resources` 文件夹。
- `SHA256SUMS.txt` 提供两个软件包的 SHA256 校验值。
- `VERIFICATION.md` 记录本版验证结果和验证范围。
- 源码可使用本页自动生成的 Source code 归档，或克隆仓库并检出 `v0.1.0`。

运行环境：Windows 10/11 x64，WebView2 运行时。软件包已包含 FFmpeg 音视频处理组件及其许可证。

## 功能

- B站视频链接、BV号、av号和 b23.tv 分享链接解析。
- 分P选择、批量任务、当前可用画质选择。
- MP4 视频、M4A 原始音频与音视频自动合并。
- 下载队列、并发控制、单任务限速、暂停/继续、失败重试。
- SQLite 保存设置和任务记录，应用重启后可继续中断任务。
- 可选保存封面、XML弹幕和SRT字幕。
- 系统托盘、单实例、打开下载目录与定位已下载文件。
- 可选 SESSDATA 登录凭据，仅保留在当前进程内存，完全退出后清除。

## 验证

16项测试通过，包含前端下载流程、断点校验、SQLite、真实B站接口和完整下载合并。实际下载并合并了一段约198.27秒的视频，ffprobe 确认同时存在视频和音频轨道。

原生窗口自动验收被 Esc 中止，完整原生界面交互验收尚未完成，详见 `VERIFICATION.md`。

## 当前范围

本版支持B站普通视频页面。账号可访问的画质以源站实际返回结果为准；字幕和弹幕取决于视频资源的可用性。

扫码登录、浏览器扩展、其他视频站点、Linux及鸿蒙客户端计划后续实现。

FFmpeg 构建来源和许可证说明见仓库 `THIRD_PARTY.md` 及软件包内的 `resources/FFMPEG-LICENSE.txt`。

# SnowDown v0.2.16

新增 Windows 桌面端视频号视频解析与下载，浏览器插件继续使用 v0.1.17。

- 自动识别视频号分享文字、短链接和官方预览详情链接，支持主输入框、剪贴板和批量输入。
- 设置 → 平台账号 → 视频号，可打开腾讯元宝官方页面，由用户完成登录后返回保存解析会话；提供检查会话和退出登录。
- 解析会话仅在本机使用 Windows DPAPI 加密保存，重启后恢复；与原三平台会话分开管理，不读取其他浏览器或微信客户端账号数据库。
- 取得视频号官方可播放资源后进入现有下载队列，支持 MP4、M4A、封面、暂停、继续和删除。
- 保存 MP4/M4A 前检查时长和媒体轨道，无法读取的内容不会显示下载成功。
- 内置插件同步到已发布的 v0.1.17；保留原插件 ZIP 字节和版本，桌面打包不会重新覆盖已发布的插件包。

## 使用

在设置 → 平台账号 → 视频号点击“打开腾讯元宝官方登录”，由用户完成登录，返回后点击“保存会话”。然后粘贴视频号分享链接并点击“解析视频”，选择输出格式并开始下载。

此功能会将用户提交的视频号链接和必要的解析会话发送到腾讯官方服务，详情见[隐私政策](https://github.com/xiaogouyo/SnowDown/blob/main/PRIVACY.md)。

## 当前范围

首批支持官方接口返回的普通可播放视频。直播、图集和需要额外解密的媒体暂不支持。画质取决于实际响应；无分辨率元数据时显示“官方可用画质”。源站不支持 Range 时会自动使用单连接，继续任务可能重新下载，并不承诺所有视频号资源都支持分段续传或多连接加速。

原有账号、设置、下载任务和文件继续沿用。此前单独登记的 Issue #1–#6 未作为此次版本的修复项。

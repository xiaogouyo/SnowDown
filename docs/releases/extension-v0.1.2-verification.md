## 功能和测试

- 前端 94 项测试通过。新增拖动几何测试：四周边界、归一化位置恢复、异常存储值、不同视口和展开卡片的约束。
- 实际打包插件中，用真实鼠标将球体从右下拖到页面中部，确认仍为 54×54 且没有误展开；页面刷新后恢复拖动位置。实际拖动展开卡片标题栏，并在 480×400 视口验证卡片没有越界。
- 实际关闭提醒，动画中仍有退出画面，随后移除节点；刷新设置与网页仍保留关闭偏好。截图确认弹窗和资源区域采用细滚动条，计算样式为 thin、浅蓝色滑块。
- 横向、纵向、对角拖动并松手后，CDP 监听没有新的 `arrive` 动画事件；初次入场动画不再因拖动样式恢复而重复播放。
- 实际点击卡片内“关闭悬浮提醒”也显示退出动画；在动画中重新开启提醒，结束后仅保留一个正常球体。减少动态效果时关闭即移除，没有残留节点。
- 继续执行平台读取、画质检查、当前页面票据、任意内容脚本下载拒绝、新标签页布局、圆角弹窗等回归。三平台使用受控页面和虚构元数据，浏览器实际下载本机生成的 H.264 / AAC 视频，保存文件与原 22,554 字节 MP4 完全一致。未把样例下载称为公网速度测试。
- 动画和拖动都在隔离资料中检查；没有读取外部浏览器 Cookie 或修改用户浏览器策略。测试截图和媒体位于忽略目录，不进入发布 ZIP。

## 实现与范围

拖动使用 Pointer Events 和 pointer capture，超过移动阈值才视作拖动，并抑制随后的误点击。结束拖动时只保存归一化位置，不在每一帧写入存储。窗口缩放时重新计算可见范围；退出、重新开启及页面切换清理临时动画。减少动态效果时取消运动过渡。

插件 v0.1.2 随桌面 v0.2.5 同步发布，也提供独立 ZIP；桌面 v0.2.4 已发布附件保持原样。未上架商店的插件需用户在扩展管理页刷新。浏览器系统边框、缩放和滚动条策略仍由浏览器管理。

可复现：`npm test`；打包后运行 `tests/extension-drag.browser.mjs`，需 Playwright（或 `SNOWDOWN_PLAYWRIGHT_PATH`）及 `.tools/v024-fixture.mp4` 测试媒体。回归使用独立资料并在退出时关闭测试浏览器。

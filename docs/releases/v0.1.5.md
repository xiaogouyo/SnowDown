SnowDown v0.1.5 · 多链接批量下载与统一设置

## 更新

- 右上角“新建下载”改为“批量下载”，点击或按 Ctrl+N 打开弹窗。原有单链接解析入口继续可用。
- 支持混合粘贴B站、抖音、小红书链接、BV/av号与完整分享文字，用换行、空格、英文或中文逗号分隔，自动识别平台并去重。每批最多 100 个链接、1000 个分P任务。
- 统一设置 MP4 视频 / M4A 音频、最高可用画质或 1080P / 720P / 480P 上限、保存目录、封面、B站弹幕与字幕、全部分P。仅应用于本批任务，不修改全局设置。
- 点击“一键下载”后按顺序解析，成功项统一加入队列，已有相同活跃任务自动跳过；解析失败的链接保留并显示原因，可修改后重试，已加入的链接不会再次提交。解析过程中关闭弹窗可取消本批提交。
- 同批任务启动间隔可设为 0 至 3600 秒，默认 3 秒。按上一个任务实际启动时间计算，遵守全局并发数，等待并发空位后启动的任务同样遵守间隔；0 秒表示不额外等待。
- 批量入队使用数据库事务，出错时整批不写入；任务与间隔持久保存，旧版本任务记录兼容。重启后中断任务仍保持暂停，点击继续恢复。
- 画质以平台及当前账号可用资源为准；指定上限时优先选择最接近的较低画质，没有较低画质时选最低可用画质，竖屏以短边分辨率比较。弹幕、字幕及全部分P主要适用于B站。

## 下载

- 安装版：`SnowDown_0.1.5_x64-setup.exe`。
- 免安装版：`SnowDown_0.1.5_Windows_x64_portable.zip`，完整解压后运行 `SnowDown.exe`，保留 `resources`。
- 附件提供 `SHA256SUMS.txt` 与 `VERIFICATION.md`。

需要 Windows 10/11 x64 与 WebView2。升级沿用任务、设置与平台登录资料。平台登录及下载范围与 v0.1.4 相同：使用软件内官方二维码登录，过期自动换码，已登录时可检查或退出。网站访问权限、风控和可用画质由各平台决定。

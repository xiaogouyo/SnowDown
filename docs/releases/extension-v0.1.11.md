# SnowDown 浏览器插件 v0.1.11

修复偶发的“页面或登录状态已变化，请重新读取”。原版 v0.1.10 在列表视频预加载期间会清空全标签页解析，统计 Cookie 更新和原生连接波动也可能误取消任务。

- 区分预览卡片与当前播放请求，其他视频加载不取消已选卡片。
- 仅识别明确的登录 Cookie，忽略 B站 b_lsid 等统计和设备/CSRF 刷新；真正登录变化仅影响对应平台。
- 稳定页面遇到失效竞态自动重读一次，避免无限重试；实际导航仍取消旧结果，权限撤销不自动重试。
- 原生连接断开仅移除桌面解析缓存，不取消浏览器解析；下载偏好切换不清空无关任务。
- 失败菜单增加“重新读取”，保留原 Logo、位置、缓存上限与双 Worker。

这是独立插件修复，桌面官方安装包仍为 v0.2.13。下载 ZIP 后覆盖原插件目录，在扩展管理页刷新 SnowDown，再刷新已有网页。

# SnowDown v0.2.15 / 插件 v0.1.15

新增插件网页资源分类、卡片预览与 ZIP 打包，桌面支持接收插件的批量打包请求。

## 浏览器插件

- 网页资源布局参考用户提供的 AixDownloader 截图：分类工具栏、尺寸和格式筛选、图片网格卡片、全选与反选，保留 SnowDown Logo 和蓝色配色。
- 分类包含图片、视频、音频、文档及播放清单；增加声明的懒加载图片、srcset 和文档链接读取，继续合并 DOM、页面资源记录与浏览器已观察的网络资源。
- 支持 URL/名称筛选、大小排序、小/大预览、文件命名模板、导出资源链接、单项下载和下载所选。
- 全选与反选作用于当前筛选结果；ZIP 打包也仅提交当前可见筛选中的已选资源。
- 浏览器将资源流式写入插件自己的临时文件，全部成功后保存 ZIP，支持中文名与重名处理。使用 STORE 格式，主要用于集合文件，不承诺缩小已压缩图片/视频的体积。

## 桌面联动

开启桌面转发并连接 v0.2.15 后，打包请求创建一个独立 ZIP 队列任务。桌面使用现有受限出站通道和下载进度机制，下载完成后生成一个 ZIP 文件。

桌面未运行或版本过旧时回退浏览器打包。桌面仅接收公开 HTTPS 文件；浏览器会话限制、服务器防盗链或重定向可能导致桌面下载失败，此时请选择浏览器下载。

每个 ZIP 最多 200 项、2 GiB。播放清单和媒体分片不能作为完整视频直接打包，请使用平台视频模式。不自动滚动网页、不提前批量解析推荐视频；滚动或播放后可重新读取资源。

安装或更新插件后，请刷新扩展管理页中的 SnowDown，再刷新网页。原账号、设置及下载内容继续沿用。之前登记的 6 个 Issue 不在本次修复范围。

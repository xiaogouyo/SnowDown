# SnowDown v0.2.14 / 插件 v0.1.14

加快 YouTube 视频与 Shorts 解析，保留原有下载、画质、缓存和浏览器联动。

- 桌面优先读取官方直接音视频，减少多播放器、HLS/DASH 清单及播放器脚本处理。快速路径最多等待 12 秒；失败或没有实际画质时自动回退完整解析，回退预算为 45 秒。其他平台保持原路径及 60 秒预算。
- 插件优先调用官方播放器接口，失败后再读取完整视频网页；没有媒体时跳过空解析任务，减少不必要的等待。仍只在用户请求时解析，不批量预加载推荐视频。
- 成功解析继续复用短期缓存和实际媒体，点击下载时不重复解析。

样例为此前提供的公开视频 `https://www.youtube.com/shorts/8fVlLJcwMeI`：桌面解析组件交替测试各三次，中位数 **8.28 秒 → 5.06 秒**，约减少 39%；匿名隔离浏览器的一次插件对比 **1.41 秒 → 0.73 秒**，约减少 48%。两端返回的样例 7 档实际分辨率一致。数值是样例结果，不代表所有视频或网络环境。

内置插件 v0.1.14。更新后在浏览器扩展管理页刷新 SnowDown，再刷新已有 YouTube 页面。桌面 v0.2.14 可由旧版正常检查更新；账号、设置与下载内容继续沿用。

官方要求登录、验证、地区访问条件及受保护内容仍按平台实际状态处理。

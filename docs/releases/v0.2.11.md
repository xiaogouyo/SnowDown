# SnowDown v0.2.11

在“连接你的浏览器”面板新增“检查插件更新”。从 GitHub 正式发布中查找最新插件版本，与正在运行的插件比较，显示更新说明、发布页面和新版 ZIP 下载入口。

- 独立插件发布与桌面发布分开识别，按插件版本排序。
- 下载核对官方附件大小与 SHA256，校验通过后保存；支持取消保存、失败重试。
- 远端插件比内置版本新时，安装入口下载新版 ZIP，避免用旧内置包替代新版。
- 内置插件升级至 v0.1.9。浏览器扩展仍需解压覆盖原目录，然后在扩展管理页刷新插件和已有网页。
- 面板内容可滚动，标题与完成按钮保持可见。沿用用户已配置的网络代理。

覆盖安装保留登录状态、设置、任务与下载内容。附件包含 Windows 安装包、免安装包、插件 ZIP、SHA256SUMS 和验证记录。

SnowDown 浏览器插件 v0.1.7 · 图标加载与旧脚本清理

- 修复页面下载入口 Logo 依赖 `chrome-extension://…/icons/32.png` 的加载方式。原 PNG 随脚本内置、解码为位图后绘制到 Canvas，页面不再请求扩展图片地址，避免跨扩展来源或网页图片策略导致的拒绝加载。Logo 像素保持不变。
- 扩展被重载或上下文失效后，旧页面脚本停止扫描和定时器、断开监听并清理按钮，不再持续尝试操作已经失效的扩展。
- 保留 B站左上角、抖音右侧操作栏、图标居中、封面原生定位、下载菜单及桌面联动；独立悬浮球保持移除。

**必须刷新扩展和网页：**覆盖原插件文件夹后，在 Edge / Chrome 扩展管理页刷新 SnowDown，再刷新已打开的 YouTube 等网页。更新前已注入的旧脚本无法被新文件直接替换。扩展错误列表会保留历史记录，可在更新并刷新网页后点“全部清除”，再观察是否有新增错误；清除历史不是本修复的实现方式。

本次为独立插件补丁，兼容桌面 v0.2.10，桌面版本号不变。桌面 v0.2.10 原发布附件内置 v0.1.6，需要用本次 v0.1.7 ZIP 单独更新；本发布不替换桌面 GitHub latest。稳定 ID、Logo 和账号／下载偏好保留。

受控 Chromium 已验证严格 `img-src 'none'`、Logo 像素一致、无页面扩展图片请求、真实 runtime reload 后旧页面清理与不再创建控件。位置、菜单及音视频下载回归通过；仍需用户在原 YouTube 页面刷新后观察实际错误列表。

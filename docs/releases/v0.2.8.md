SnowDown v0.2.8 · 视频预览下载与多站点接入

- 内置浏览器插件 v0.1.4。保留 SnowDown 原 Logo，在视频及视频预览卡片旁显示下载按钮，展开为圆角格式菜单，可选择实际可用画质、音频或封面。
- 支持在列表预览卡片直接读取目标视频，校验卡片与当前目标，避免下载到相邻视频。插件弹窗同步采用紧凑格式列表，延续浅色圆角风格。
- 新增共享站点目录，覆盖 DataTool 公开展示的站点类别，插件与桌面统一识别；桌面内置独立 yt-dlp / Deno 组件，插件优先读取浏览器已加载媒体，也可转交桌面解析、下载。
- 浏览器支持常见 HLS 多画质及分离音轨的合并，音频选项实际导出 M4A，不虚构 MP3 格式或不存在的画质。
- 保留三平台扫码登录、账号同步、下载队列与安装升级的文件校验。新增下载组件纳入实际安装负载清单，覆盖安装保留账号、设置、任务与下载内容。

**插件更新：**在 Edge / Chrome 扩展管理页刷新 SnowDown，再刷新已有视频页面。新增站点需在插件偏好设置点击“启用更多平台与预览下载”，由浏览器确认站点权限。默认授权范围没有扩大；未授权时原有三平台仍可使用。

**兼容性范围：**50 类站点进入共享识别目录，不代表所有页面均可下载。新增站点以公开页面或浏览器当前已加载、可访问的媒体为基础；登录限制、直播、图集和 DRM 媒体不保证支持。账号 Cookie 自动同步仍限 B站、抖音和小红书。详见[平台范围与验证](https://github.com/xiaogouyo/snowdown/blob/v0.2.8/docs/platform-support.md)。

本版已验证真实 YouTube 解析与有声下载、Archive 元数据解析、浏览器到桌面的下载转发，以及受控页面中的 47 个新增站点识别、预览菜单、HLS 合并和音频导出。未将受控测试等同于全部实际网站验证。

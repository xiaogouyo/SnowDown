# Windows v0.1.1 验证记录

日期：2026-10-24。目标：Windows 10/11 x64。

## 已通过

- TypeScript 检查与 Vite 生产构建。
- 前端 8 项测试：原有下载流程，以及集成窗口按钮、官方二维码状态、关闭登录页停止轮询、过期刷新、确认后展示已保存账号。
- Rust 17 项测试，包含显式启用的联网测试：官方二维码生成/等待扫码、B站解析/CDN、完整媒体下载/FFmpeg 合并，以及原有输入、SQLite、断点与音视频测试。
- 会话持久化：使用模拟凭据执行 Windows 当前用户 DPAPI 加密保存、覆盖写入、重新打开读取；确认文件不含明文凭据；退出后删除；损坏文件安全回退；过期/取消请求不能恢复已退出的账号；断网保留已保存会话。
- 实际下载与合并回归：约 198.27 秒的B站样例，ffprobe 检查视频和音频轨道。
- 异形安装器核心 12 项断言：中文/空格路径、非法/相对路径拒绝、NSIS 参数格式、SHA256 校验、阶段信息和临时目录清理边界。
- 安装器隔离集成：以唯一 QA 产品名称、独立注册表标识及工作区中文目录，运行与发布版相同的外层安装程序，验证负载解包、完整安装、原生程序与 FFmpeg 哈希、卸载注册信息、重装和真实完成阶段；卸载移除程序和组件，保留无关用户文件。
- 运行中客户端保护：使用测试程序占用安装目标，前端与 NSIS 后端均拒绝覆盖，测试进程仍存活。没有结束用户正在运行的 SnowDown。
- 发布安装程序内嵌负载 SHA256 校验与解包自检。
- 异形布局的安装前、安装中、完成状态均从实现代码离屏渲染并检查。透明素材为 RGBA，窗口支持 alpha 透明度。

## 验证范围

真实账号的手机扫码确认、账号画质和真实会话重启恢复，需要用户以自己的账号验收。本轮仅调用官方未登录二维码接口，持久化测试使用独立模拟凭据，不读取浏览器 Cookie。

原生桌面窗口全流程的鼠标/键盘交互验收尚未完成。安装器视觉检查使用自身代码的离屏渲染，安装/升级/卸载流程通过独立命名空间的实际负载执行验证。

尚未覆盖不同 DPI/多屏组合、休眠恢复、所有低磁盘/权限错误、全部会员画质与长期运行。B站会话有效期由源站决定，失效后需重新扫码。

## 重现

```powershell
npm run build
npm test
cargo test --manifest-path src-tauri/Cargo.toml --lib -- --include-ignored
npm run desktop:build
powershell -NoProfile -ExecutionPolicy Bypass -File tests/installer-integration.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/package-portable.ps1
```

安装程序：`src-tauri/target/release/bundle/snowdown/`。内部 `bundle/nsis/` 负载不作为公开下载的安装界面。

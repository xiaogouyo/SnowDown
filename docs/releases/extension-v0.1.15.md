# SnowDown 浏览器插件 v0.1.15

网页资源模式更新为参考 AixDownloader 截图的分类与网格布局，保留 SnowDown 原 Logo 和配色。

- 图片、视频、音频、文档、清单分类；尺寸范围、格式、URL/名称筛选。
- 图片卡片预览、大小排序、小/大预览，全选、反选和单项下载。
- 文件名模板、导出链接、下载所选及 ZIP 打包。
- 读取当前页面的 DOM、已观察请求、懒加载图片声明、srcset 和文档链接；页面滚动或播放后可重新读取。
- 浏览器 ZIP 使用临时文件，避免把整个资源包放进内存；中文文件名、重名处理及取消支持。
- 连接桌面 v0.2.15 后可转发为一个 ZIP 队列任务；未连接或桌面版本过旧时回退浏览器打包。

ZIP 上限 200 项、2 GiB；只打包当前筛选中的已选文件。清单和分片请使用平台视频模式。ZIP 使用 STORE 格式，不保证减少媒体文件体积。

解压覆盖原插件目录，在扩展管理页刷新 SnowDown，再刷新已有网页。站点权限与三平台账号同步方式保持不变。

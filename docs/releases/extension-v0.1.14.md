# SnowDown 浏览器插件 v0.1.14

加快 YouTube 视频和 Shorts 解析：优先官方播放器接口，成功时不再重复获取完整视频网页；仅在接口失败时保留网页读取和桌面解析回退。没有媒体时跳过空解析任务。

保留原 Logo、左上角封面入口、短期解析缓存、有限分块下载、音视频合并及浏览器会话使用方式。

匿名隔离浏览器的样例对比：v0.1.13 约 1.41 秒，v0.1.14 约 0.73 秒；返回画质相同。固定 1.8 秒网页延迟的回归测试确认新版不请求完整网页，同时最终输出音视频仍可解码。网络、视频与登录条件会影响实际耗时。

同批桌面版为 v0.2.14。解压覆盖插件原目录，在扩展管理页刷新 SnowDown，再刷新网页；独立使用的站点授权方式保持不变。

## 行为与范围

旧实现仅在主窗口获得焦点时检查剪贴板，忙碌时直接跳过。现在由 Rust 定时读取 Windows 剪贴板序列号，仅在变化时读取文本；打开失败或文本暂未就绪时不把该变化标记为已处理，下次继续尝试。平台依据：[Windows 剪贴板序列号](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-getclipboardsequencenumber)、[Tauri 系统托盘](https://v2.tauri.app/learn/system-tray/)。

启用自动解析后，在原生后台串行准备最新识别的视频链接，收到新链接、关闭识别或手动处理同一链接时取消旧工作；状态版本和匹配编号防止迟到结果覆盖新状态。临时网络错误不进行无限自动请求，可手动重试或重新复制。后台结果保留于内存，不保存剪贴板历史，不自动创建下载任务。

本次真实网络解析覆盖公开B站分P；抖音、小红书仍调用原有平台解析与会话模块，没有更改其站点实现。平台风控、登录失效和网络问题仍可能导致解析失败，应用会显示可重试状态。托盘布局用原生主屏验证，多屏与缩放坐标由纯计算测试覆盖，没有声称已连接多台显示器验证。

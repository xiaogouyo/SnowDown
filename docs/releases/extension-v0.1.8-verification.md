## 实际 YouTube 检查与限制

使用本机已打包提取器对用户截图中的公开 YouTube 视频和此前公共样例进行只读元数据检查，均在约 5.7 秒返回官方登录／非机器人确认提示，未计为实际解析下载成功。浏览器已有可播放会话可能提供媒体，但本次不读取或自动操作用户 Edge 资料、登录和验证。新浏览器会话读取、观察媒体、超时和错误提示通过受控测试，仍需用户刷新插件与实际网页后确认。

桌面安装包和 Rust 内核不修改，仍为 v0.2.10。原有三平台账号同步范围不扩大，没有为 YouTube 导入 Cookie、执行签名脚本或提供验证码绕过。

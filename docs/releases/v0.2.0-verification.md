## 范围与限制

扩展尚未上架商店。普通 Windows 环境中不能从软件静默强装未上架插件；软件准备文件、注册原生通道、绑定并打开管理页后，用户需完成浏览器的“加载已解压的扩展”确认。本次未声称已在用户真实 Chrome／Edge 资料中安装插件。

真实公网视频覆盖公开 B站；抖音、小红书扩展解析使用响应样例与已有站点解析边界验证，会话导入使用虚构的隔离数据。本次没有重复验证用户手机确认登录后所有抖音／小红书视频、验证码、会员内容或 CDN 变体；官方页面结构变化可能需要适配。

资源模式观察已加载／已请求的媒体，不能保证找到尚未加载、受权限限制或加密的全部资源。不提供 DRM 解密、直播录制、播放清单展开或小红书图集解析。浏览器内存合并不适合超大文件，建议使用桌面端。服务器不支持范围或资源变更时仍会回退重下，完整保留 v0.1.10 的下载校验策略。

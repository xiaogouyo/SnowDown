SnowDown v0.1.8 · 后台剪贴板与托盘菜单优化

## 修复与改进

- 剪贴板识别从“主窗口获得焦点时检查”改为原生后台监听变化。软件最小化、隐藏到托盘后仍可识别新复制的视频链接，临时占用时自动重试。
- 开启“识别后自动解析”后，由原生后台准备最新链接的解析结果；回到主窗口且没有其他弹窗时展示，不自动下载。保留手动编辑的输入，点击“查看结果”使用已准备的结果。
- 连续复制不同链接时取消旧解析；通过状态版本过滤迟到结果。手动解析不会在后台重复触发，失败可点击重试或重新复制链接。关闭识别立即取消后台工作并清除待展示结果。
- 托盘右键菜单使用与软件一致的白色圆角面板、蓝色选中样式、图标和字体，保留打开软件、打开下载目录、退出三个操作；支持方向键、Esc、失焦关闭和多屏工作区域定位。双击托盘仍可恢复主窗口。
- 保留三平台扫码、批量下载、66 节点更新镜像和更新提醒。

## 下载

- 安装版：`SnowDown_0.1.8_x64-setup.exe`。
- 免安装版：`SnowDown_0.1.8_Windows_x64_portable.zip`，完整解压后运行 `SnowDown.exe`，保留 `resources`。
- 附件提供 `SHA256SUMS.txt` 与 `VERIFICATION.md`。

需要 Windows 10/11 x64 与 WebView2。可从右上角版本号或“关于 → 检查更新”升级。保持免安装方式的用户可下载 ZIP，退出后覆盖原文件夹。

剪贴板仅在启用识别时自动读取，不记录剪贴板历史。后台保留最新识别的视频链接及解析结果，完全退出软件后不再监听；自动解析需要另行开启，仍受平台会话和网络状态限制。

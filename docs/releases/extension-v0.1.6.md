SnowDown 浏览器插件 v0.1.6 · 卡片原生定位

- 预览按钮直接挂载到对应封面容器，随网页原生布局、滚动和 CSS 变换一起移动，取消全局浮层坐标跟随，解决图标漂移、错位和悬空。
- 同一视频出现在多张卡片时分别绑定按钮，避免一个按钮在卡片之间跳动。卡片移除或复用后清理旧按钮和旧解析结果。
- 菜单使用浏览器顶层弹出层，保持圆角白底；展开时可越过封面裁切，页面滚动时收起回对应封面，不留下悬空菜单。修复点击封面内按钮误触发原视频链接的问题。
- 保留 30px 小图标、原 Logo、半透明外框、现有平台解析与桌面联动。退出或关闭提醒后恢复插件修改的容器样式。

**更新插件：**下载本发布中的 `SnowDown_BrowserExtension_0.1.6.zip`，解压覆盖已安装插件的原文件夹；在 Edge / Chrome 扩展管理页刷新 SnowDown，再刷新已有网页。插件 ID 与偏好保留。

这是独立插件补丁，桌面正式版仍为 v0.2.9。已发布的桌面 v0.2.9 安装包内置 v0.1.5；需使用本次插件 ZIP 更新。原生消息协议兼容现有桌面版，不需要更新下载内核。本发布不占用 GitHub 的桌面“最新版本”入口。

验证使用隔离 Chromium：旧发布包可复现滚动后立即测得 27px 偏差，新版在滚动回调执行前仍保持 6px 锚点间距；CSS 变换、重复卡片、内层裁切、对话框、菜单和 B站／抖音解析下载回归通过。实际用户 Edge 窗口检查被工具停止，未将测试页面结果表述为实际网页全覆盖。

SnowDown v0.2.3 · 简约模式连续变形动画

- 点击左上角 SnowDown 标志切换时，输入框从完整界面的实际位置连续移动到简约模式，并逐渐改变宽高、圆角、阴影和字号。
- 右侧蓝色“解析视频”按钮逐渐收窄、变色，下载图标的线条连续变为简约箭头；粘贴按钮与文字自然退场。
- 背景以实际鼠标点击位置为圆心向外扩散；切回完整模式也使用连续过渡，键盘操作以标志中心为扩散起点。
- 统一完整与简约模式 Logo 的位置、字号、间距和文字基线；切换中由同一个固定 Logo 贯穿画面，修复几像素偏移和扩散边缘双影，最小窗口下也保持对齐。
- 保留输入、解析结果、格式选项和下载队列；自动解析与剪贴板结果在切换结束后继续处理，避免中途改变布局。重复点击不会叠加动画，窗口缩放或页面关闭会清理临时画面。
- 支持系统“减少动态效果”偏好，启用后直接切换。浏览器插件仍为 v0.1.0，无需重新安装。

附件提供 Windows x64 安装版、免安装版、浏览器插件、SHA256 校验及验证记录。升级继续沿用原有设置、登录状态和下载内容。

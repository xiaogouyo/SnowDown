SnowDown v0.2.3 · 插件 ZIP 与图标安装引导

- 浏览器插件面板原文件夹说明卡改为“下载 ZIP”。当联动安装不可用时，可把软件内置插件直接保存为 ZIP，解压后本地加载；生成安装包不依赖 GitHub 网络。
- 移除底部两段说明和长列表，改为下载、解压、开发者模式、加载文件夹、固定图标的五步图标流程。鼠标悬停或键盘聚焦时显示对应提示。
- 流程不显示数字徽标；卡片悬停时轻微上浮、放大并增强阴影，移开平滑恢复。键盘聚焦有相同反馈，并遵循系统减少动态效果设置。
- 自动准备联动、浏览器检测、安装／管理入口继续保留；ZIP 保存取消不会误报成功，安装失败后仍可使用 ZIP 备用入口。
- 上一版连续动画和 Logo 对齐功能已归档为 v0.2.2，GitHub Release、标签、源码及安装包内部版本均同步修正。本版为新的 v0.2.3，保留上述动画能力。

此前安装过误标 v0.2.3 动画版的用户，请手动下载安装本版一次。同版本号不会触发版本升级提示；升级保留登录、设置和下载内容。

附件提供 Windows x64 安装版、免安装版、浏览器插件 v0.1.0、SHA256 校验与验证记录。

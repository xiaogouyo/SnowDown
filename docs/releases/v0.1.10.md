SnowDown v0.1.10 · 断点续传与多连接下载

## 视频与更新下载

- 视频和版本更新共用持久化分段下载内核，默认每文件 8 连接；设置中可选择 1、2、4、8、16 连接，同时保留 1 至 4 个并发任务。
- 保存每个分段的进度和摘要，暂停、网络中断或软件重开后可继续。继续任务时重新解析媒体地址，下载地址变化不影响相同资源的有效进度。
- 更新窗口增加“暂停下载”和“继续下载”，显示实际连接数、速度与已续传大小。后台下载、收起窗口和切换界面模式仍会继续传输。
- 同一更新包可在镜像之间续传，最终仍核对官方 GitHub 的文件大小和 SHA256，安装前再次校验。
- 检查 Range 响应、资源标识及本地分段摘要；文件发生变化时重新下载，损坏分段单独重下。不支持安全分段的服务器自动使用单连接完整下载。
- 所有分段共同遵守单任务限速；全局最多同时传输 32 个连接。完全退出时先保存下载进度，重开后可手动继续。
- 兼容旧版任务和设置；具有匹配强 ETag 的旧版视频临时文件可迁移续传。

## 下载

- 安装版：`SnowDown_0.1.10_x64-setup.exe`。
- 免安装版：`SnowDown_0.1.10_Windows_x64_portable.zip`，完整解压后运行 `SnowDown.exe`，保留 `resources`。
- 附件提供 `SHA256SUMS.txt` 与 `VERIFICATION.md`。

需要 Windows 10/11 x64 与 WebView2。可从右上角版本号或“关于 → 检查更新”升级。继续使用免安装方式可下载 ZIP，完全退出后覆盖原文件夹。更新不会清除已有任务、设置与账号资料。

多连接提速取决于网络、磁盘与站点限制。服务器不支持分段、不能可靠识别资源或资源已变化时，继续下载可能从头开始。抖音、小红书沿用已有解析与账号实现，本版改进取得媒体地址后的下载过程。

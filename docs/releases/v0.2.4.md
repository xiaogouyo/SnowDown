SnowDown v0.2.4 · 解析提速与视频悬浮下载

- 抖音、小红书解析改为直连与后台网页并行取首个成功结果，避免直连超时后才加载网页。提高元数据轮询频率，复用最高画质默认解析缓存；同平台请求串行协调，重复会话保存不再清空缓存。
- 登录检查缩短轮询间隔，稳定本人账号证据可更早确认；同一会话 20 秒内已确认结果可复用。平台忙碌时尽快返回提示，不再长时间排队。无法确认时仍保留登录状态。
- 内置浏览器插件升级至 v0.1.1：新标签页使用完整窗口布局，弹窗使用圆角外框；平台解析不再扫描整页图像和背景样式。
- 发现可见视频后，从网页右侧以挤压动画出现悬浮球。点击球体连续展开成圆角下载卡片，可选择画质、跟随插件下载方式或单次使用浏览器下载。收起后恢复球体。
- 插件偏好设置增加“视频悬浮球提醒”开关，卡片内也可关闭；状态持久保存并同步到已打开页面。三平台默认可用，其他网页需先获得资源模式站点授权。
- 网页悬浮操作只使用当前标签页解析得到的短时下载凭据，页面切换、过期或无效画质不能复用旧设置；不向网页开放账号同步或原生消息接口。

附件提供 Windows x64 安装版、免安装版、插件 v0.1.1 ZIP、SHA256 与验证记录。插件为本地加载版本，更新文件后需要在浏览器扩展管理页刷新插件；已有网页可刷新一次。桌面升级保留原有账号、设置、任务和下载内容。

提速效果取决于网络和平台响应；不能保证所有视频立即解析。验证码、图集、直播及受限内容维持原有支持范围。

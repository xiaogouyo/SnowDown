# SnowDown 浏览器插件 v0.1.12

修复 YouTube 视频封面上的雪花下载图标可见却无法点击的问题。

- 下载按钮挂载到外层封面，避开缩略图内的悬停预览遮挡层。
- 兼容新旧封面结构；悬停隐藏、替换内层图片时保持下载入口可用。
- 保留原 Logo、左上角位置、居中外框及原生滚动、裁切和菜单行为。

桌面官方版本保持 **v0.2.13**，本次独立更新插件。下载 `SnowDown_BrowserExtension_0.1.12.zip`，完整解压覆盖插件原目录，在扩展管理页刷新 SnowDown，再刷新已有网页。本机已准备目录的文件可直接刷新使用。

验证包括：旧版遮挡复现、新旧封面真实鼠标点击、匿名公开 YouTube 搜索页点击，以及滚动定位、缓存竞态、原 Logo、B站预览与实际下载解码回归。详见附件 `VERIFICATION.md`。

本次修复点击入口，不代表所有 YouTube 视频均可解析下载；实际结果仍取决于可用媒体、登录状态和站点访问条件。

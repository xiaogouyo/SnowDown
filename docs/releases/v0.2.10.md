SnowDown v0.2.10 · 插件版本检测与视频入口调整

- 浏览器插件面板新增版本检测，分别显示实际连接插件版本与软件内置版本。旧插件未上报版本、版本落后，或同为 v0.1.6 但尚未加载本次代码时提示更新／刷新，避免将“已连接”当成已更新。
- 内置插件仍为用户指定的 v0.1.6，使用兼容修订标记区分本次代码；移除独立悬浮球，保留封面／播放器旁的下载入口。原“悬浮球提醒”设置改为“视频下载入口”。
- B站按确认的绿框移到封面左上角。抖音视频播放器入口移到右侧操作栏上方，按操作栏中心对齐；无法确认操作栏时放在播放器右侧约 35% 高度的备用位置。
- 修正图标按钮的默认内边距与盒模型，20px 原 Logo 在 30px 半透明外框中居中。保持按钮直接绑定封面、重复卡片独立定位及菜单滚动收起。
- “更新插件”准备本机内置文件并打开扩展管理页，仍需用户刷新扩展与已有网页。保留原插件 ID、账号、设置、下载任务及内容。

**更新方式：**安装桌面 v0.2.10，然后在“浏览器插件”面板检查版本、更新插件；在 Edge / Chrome 扩展管理页刷新 SnowDown，再刷新原网页。也可下载本 Release 的 `SnowDown_BrowserExtension_0.1.6.zip`，覆盖原插件目录。此前独立发布的同版本插件 ZIP 不包含本次调整，以本桌面 Release 附件为准。

前端、Rust、隔离浏览器位置与菜单下载回归通过。真实抖音 DOM 可能变化，操作栏识别失败时使用上述备用位置；受控页面的验证不等于所有实际页面验证。

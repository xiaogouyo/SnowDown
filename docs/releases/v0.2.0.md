SnowDown v0.2.0 · 浏览器插件与自动更新

## 浏览器联动（插件 v0.1.0）

- 左侧新增浏览器插件贴片，检测 Google Chrome 和 Microsoft Edge，未安装时提供官方下载入口；安装时准备插件文件、注册原生通道并自动绑定。
- 插件使用与软件一致的浅色、圆角与雪花图标。点击插件界面的 SnowDown 标志可在平台视频与网页资源模式之间切换。
- 读取B站、抖音和小红书视频及可用画质，沿用浏览器中的平台账号；可选择浏览器下载或转发到桌面队列。分离 MP4 音视频可在浏览器下载页合并。
- 网页资源模式可按视频／图像／音频、格式、尺寸与关键词筛选，并批量下载；仅观察已加载和已请求的资源，需要单独授权站点访问。
- 连接后可自动同步三平台账号，Windows 加密保存；从软件贴片安装时默认启用桌面转发和账号同步，插件设置可关闭。软件离线时自动回退浏览器下载，重新启动软件后恢复连接。
- 普通 Windows 浏览器要求用户确认加载未上架扩展；软件会打开管理页与插件目录，最后需开启开发者模式并选择“加载已解压的扩展”。当前没有扩展商店上架地址，不会修改企业策略来强制安装。

## 自动更新与账号头像

- 更新包下载且官方 SHA256 校验通过后，在屏幕右下角显示独立通知，即使主窗口隐藏也可看到。
- 点击“安装更新”后保存下载进度并暂停，自动退出、覆盖原目录安装并重新启动；无需再次选择目录或点击安装完成。
- 新程序启动后清理旧更新包和下载缓存；安装器按文件清单清理已停用且未被修改的旧程序文件，保留未知文件。
- Cookie、平台登录资料、任务、下载内容和设置保留，新版本沿用原数据目录。
- 偏好设置支持显示抖音、小红书账号头像和名称，在扫码、检查登录或浏览器同步时读取并保存。已有账号可点“检查登录”刷新头像。

## 下载

- 安装版：`SnowDown_0.2.0_x64-setup.exe`。
- 免安装版：`SnowDown_0.2.0_Windows_x64_portable.zip`，完整解压后启动 `SnowDown.exe`。
- 独立插件：`SnowDown_BrowserExtension_0.1.0.zip`，完整解压后加载包含 `manifest.json` 的文件夹。
- `SHA256SUMS.txt` 与 `VERIFICATION.md` 提供校验和验证范围。

Windows 10/11 x64，需 WebView2；浏览器插件需要 Chromium 116+。抖音、小红书的在线解析仍受平台页面、账号权限和风控影响。播放清单、加密内容、直播和尚未加载的资源不保证可下载。

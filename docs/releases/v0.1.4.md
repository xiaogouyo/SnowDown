SnowDown v0.1.4 · 三平台官方二维码登录与自动换码

## 更新

- 抖音、小红书改为软件内显示官方二维码，使用对应手机 App 扫码确认，无需打开独立登录窗口。二维码来自平台官方页面，软件不收集账号密码。
- B站、抖音、小红书的二维码均支持过期自动更新：响应过期或达到有效期时重新获取，官方页面自行换码时同步更新图片。
- 三个平台的已登录界面统一为“退出账号”“检查登录”，移除官方验证窗口、手动保存会话与重新扫码入口。
- 抖音、小红书退出时，等待软件内该平台独立网页资料清理完成，再清除加密会话；再次登录不会自动恢复已退出的旧会话。外部浏览器账号不受影响。
- 切换平台或关闭账号面板后停止轮询，丢弃已取消请求的结果；普通登录、检查登录、过期重试都不会修改视频输入框或自动解析。
- 检查登录时如平台明确显示未登录，则提示重新扫码；网络异常或暂时无法确认时保留已保存账号并报告错误。

## 下载

- 安装版：`SnowDown_0.1.4_x64-setup.exe`。
- 免安装版：`SnowDown_0.1.4_Windows_x64_portable.zip`，完整解压后运行 `SnowDown.exe`，保留 `resources`。
- 附件提供 `SHA256SUMS.txt` 与 `VERIFICATION.md`。

需要 Windows 10/11 x64 与 WebView2。升级沿用任务、设置和平台登录资料。二维码确认由各平台手机 App 完成；平台风控、验证码或数据结构变化可能导致无法登录，此时会在软件内提示重试，不再弹出官方验证窗口。视频访问与可用画质由平台和账号权限决定。

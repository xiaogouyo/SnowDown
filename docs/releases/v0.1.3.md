SnowDown v0.1.3 · 官方登录与链接解析分离

## 修复

- 官方窗口仅用于登录或验证，关闭后保存登录状态，不再读取网页当前视频作为下载来源，不替换输入框链接，也不自动解析。
- 登录入口改为“登录抖音”“登录小红书”，平台账号面板改为“打开官方登录”“保存登录状态”，保存时不再自动重试。
- 粘贴目标视频链接并点击“解析视频”，即可在软件内选择画质和下载。抖音会在后台复用软件自己的平台登录资料读取目标视频，无需每个视频都打开官方窗口播放。
- 后台解析保持隐藏和静音，取得详情或超时后停止页面加载。平台内并发解析按顺序进行，并校验返回数据的视频 ID，避免下载队列中的不同链接互相干扰。
- 从登录窗口返回时暂停剪贴板自动解析，保留用户正在输入的下载链接。会话保存失败会明确提示。

## 下载

- 安装版：`SnowDown_0.1.3_x64-setup.exe`。
- 免安装版：`SnowDown_0.1.3_Windows_x64_portable.zip`，完整解压后运行 `SnowDown.exe`。
- 附件 `SHA256SUMS.txt` 为校验值，`VERIFICATION.md` 为验证记录。

需要 Windows 10/11 x64 与 WebView2。升级沿用已有任务、设置和软件内的平台登录资料。视频访问与画质仍以平台及账号权限为准；遇到登录或验证要求，在官方登录窗口处理后重新点击解析。

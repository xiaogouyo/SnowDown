- 前端 13 个文件、102 项测试通过，TypeScript / Vite 生产构建通过。新增精选列表的当前视频匹配、camelCase React 播放器数据、循环引用、H.264 备用地址、晚加载恢复、相邻视频拒绝、验证码页面提示及桌面共享提取脚本测试。
- Rust 原生 74 项通过，5 项公网/专项测试默认忽略；新增官方列表路由白名单、非官方/账号路由拒绝、列表条目按当前 ID 筛选和不完整缓存拒绝。
- 实际 MV3 插件在隔离 Chromium 中通过 Fetch URL 对象、XHR JSON、已播放 React 播放器及 SPA 弹层切换验证；桌面注入的同一份脚本也能取得匹配的视频详情。夹具使用虚构视频 ID 和本机生成的视频，没有使用真实浏览器 Cookie。

SnowDown v0.2.5 · 任务删除、分段下载与覆盖安装改进

- 完整模式和简约模式均可直接删除下载任务，包括排队、下载中、合并中和已暂停任务。删除会停止后台任务并移除记录，待工作线程退出后清理该任务的临时分段；已经保存的视频、封面和字幕保留。
- 分段下载增加每连接 256 KiB 写缓冲，减少小块网络数据触发的磁盘调度；进度检查点由每 1 MiB / 500 ms 调整到每 8 MiB / 2 秒。暂停和连接中断仍主动保存并校验分段；系统异常断电时，未提交的部分会重新下载。
- 同一引擎继续用于视频和软件更新。实测确认 8、16 个连接确实并发发送 Range 请求；服务器不支持安全分段时回退单连接。连接数不会突破平台、线路或磁盘的吞吐上限。
- 安装器统一将已有软件目录作为覆盖升级处理，升级前检查全部待替换程序文件的占用和权限；避免组件被锁定时先覆盖主程序。NSIS 文件写入失败时明确终止，不再按成功继续。覆盖后逐个校验程序文件，再清理清单内未修改的旧程序组件。
- 安装日志保存到 `%LOCALAPPDATA%\SnowDown\Logs\setup-*.log`，记录版本、安装阶段、后端退出码及占用的程序文件；不记录 Cookie 或命令行参数。安装出错时提示日志位置。升级保留原有登录状态、偏好设置、下载记录和下载内容。
- 内置浏览器插件同步至 v0.1.2：悬浮球与展开卡片标题栏支持自由拖动、位置记忆和边界约束；关闭提醒时连续缩小退场，支持减少动态效果；弹窗和下载卡片采用细圆角滚动条。
- 修复松开拖动后反复播放横向入场变形的问题。入场动画只播放一次，拖动和松手保持球形。
- 桌面端接入 Windows 原生通知中心：识别视频链接、任务实际开始和下载完成时提醒；同类事件去重。通知不包含原始分享链接或登录凭据，点击提醒可返回软件。安装版与免安装版登记 SnowDown 名称和图标，不修改系统通知开关或勿扰偏好。

附件提供 Windows x64 安装版、免安装版、插件 v0.1.2 ZIP、SHA256 与验证记录。更新插件文件后，请在浏览器扩展管理页刷新插件，已有视频页面也刷新一次。

测速使用受控的按连接限速服务器，用于验证真实并发和输出一致性，不代表所有平台的公网下载速度。暂未取得本次用户安装失败的原始错误文本，安装器针对覆盖路径、文件占用及失败反馈进行了修复和回归。

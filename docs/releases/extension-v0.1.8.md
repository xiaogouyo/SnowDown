SnowDown 浏览器插件 v0.1.8 · 侧栏对齐与 YouTube 读取

- B站保持已确认的左上角，其他平台预览卡片保持右上角。抖音卡片内的小预览播放器不再误用完整视频页布局。
- 抖音完整播放器按实际操作按钮的中心定位，处理侧栏的宽度和内边距，不再简单按外层容器中心对齐；可识别右侧成组的操作按钮。识别失败时仍使用明确的备用位置。
- 新增 YouTube 目标观看页播放器 JSON 读取，严格核对视频 ID，不执行目标页脚本；支持其实际提供的 MP4 视频和独立音轨，不再将 `og:video` 的嵌入页面当成视频文件。
- 在已播放的 YouTube 观看页中，支持使用同一视频的已观察媒体请求，排除预取／广告混杂及不能安全还原的分段地址。当前播放器响应可用于恢复 SPA 切换后的目标视频。
- 同一目标的解析请求合并，YouTube 桌面解析等待有明确期限，页面操作也有总超时。官方登录验证、签名资源或网络失败会提示处理方式，避免无限停在“正在读取”。

**更新：**下载此 Release 的 v0.1.8 ZIP，覆盖原插件文件夹，在 Edge / Chrome 扩展管理页刷新 SnowDown，然后刷新已有网页。本机准备目录已更新。插件兼容桌面 v0.2.10，独立悬浮球保持移除，原 Logo、ID 和偏好保留。

**YouTube 限制：**本机独立提取器对用户截图中的公开视频返回了官方“登录确认非机器人”提示，不能把受控测试通过等同于该真实页面已经下载成功。若预览页没有直接可用资源，请进入目标视频、使用现有官方会话播放后重新读取；官方验证仍需用户完成，不提供访问限制绕过。仍受限的资源会给出错误，而非承诺任意视频可下载。

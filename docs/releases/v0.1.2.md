SnowDown v0.1.2 · Windows

## 更新

- 统一状态、画质、并发数下拉菜单的颜色、圆角、选中态与键盘交互，修复系统默认菜单与软件风格不一致的问题。
- 长链接保持输入区宽度，解析时清除追踪参数；小红书必要的分享访问参数会保留。界面显示平台与简短来源摘要。
- 试验接入抖音视频、小红书视频笔记，支持完整分享文字和分享短链接，沿用下载队列、暂停/继续、MP4 与 M4A 输出。
- 新增软件内官方网页会话：点击“官方页面解析”，完成登录或验证并播放当前视频，关闭官方窗口后返回软件自动解析。各平台会话分别由 Windows 加密保存；B站继续使用官方二维码登录。抖音支持分离的视频、音频流自动合并。
- 新增回到软件时识别剪贴板、“粘贴并解析”与 Ctrl+Shift+V。默认识别后提示，可在设置关闭或开启自动解析；下载仍由用户选择后开始。
- 设置内容可滚动，保存按钮保持可见；安装器文字同步为三平台入口。保留一体化窗口按钮与二次元异形安装器。

## 下载与使用

- 安装版：`SnowDown_0.1.2_x64-setup.exe`。
- 免安装版：`SnowDown_0.1.2_Windows_x64_portable.zip`，完整解压后运行 `SnowDown.exe`，保留 `resources`。
- `SHA256SUMS.txt` 为软件包校验值；`VERIFICATION.md` 记录测试结果与范围。

需要 Windows 10/11 x64 与 WebView2，已包含 FFmpeg。异形安装器使用系统 .NET Framework 4.6.2+。

抖音、小红书首批仅支持可访问的视频链接，图集、图文、直播、私密内容和合集暂不支持。平台可能要求登录或验证，分享参数也可能失效。抖音样例已从软件内官方页面读取详情，实际下载并合并为约 444.17 秒的有声 MP4；小红书由用户反馈正常。实际可用性以平台返回的媒体数据和账号权限为准。

B站公开视频的实际解析、下载、合并已回归验证。升级保留本机任务与设置；关闭主窗口后下载继续在托盘运行，完全退出请使用托盘菜单。

# SnowDown 浏览器插件 v0.1.13

新增 YouTube 官方播放器解析，支持公开视频与 Shorts 的真实画质、音频和下载。

- 在 YouTube 页面使用官方播放器接口及当前浏览器会话，读取与目标视频 ID 匹配的资源，不依赖第三方解析网站。
- 优先直接 MP4 音视频，合并为有声视频；画质去重，并优先兼容的 H264 资源。
- 对已知大小的 YouTube 媒体采用 128 KiB 有限分块，逐块校验范围、总长度和完整性；小文件先完整读取再合并，避免网络读取阻塞合并。每个输入的预读取上限为 128 MiB，超过上限仍使用流式读取，大文件建议桌面端。
- 无直接资源时尝试官方播放清单或桌面解析；桌面联动使用明确且更长的解析超时，菜单仍可关闭，不阻塞主站页面。
- 保留 v0.1.12 的封面点击修复、原 Logo 和左上角位置。

下载插件 ZIP 并解压覆盖原目录，在扩展管理页刷新 SnowDown，再刷新 YouTube 页面。首次使用更多站点，需在插件设置中开启并授权。

同批提供桌面 **v0.2.13 YouTube 修订包**，详见桌面 Release 的补充下载。桌面版本号按要求保持不变，已安装 v0.2.13 需要手动安装修订包。

用户提供的公开 Shorts 已完成插件独立解析、实际下载与音视频解码验证；桌面软件也已完成同视频下载。官方要求登录、验证、地区限制、直播或受保护内容仍按平台实际状态处理，不保证所有内容可下载。

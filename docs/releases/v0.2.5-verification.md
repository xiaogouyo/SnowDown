# SnowDown v0.2.5 验证记录

- `npm test`：12 个文件、94 项测试通过。包括下载中任务的删除入口、状态推送后任务消失、模式切换，以及插件拖动边界和位置恢复。

- 单独运行 `controlled_parallel_speed_comparison`：同一个 8 MiB、每连接限速的本机服务器，1 / 8 / 16 个连接分别耗时 4573 / 602 / 416 ms；实测峰值连接数分别为 1 / 8 / 16，输出文件 SHA256 全部一致。该结果验证并发能力，不是公网提速承诺。

- 实际鼠标分别横向、纵向和对角拖动球体，CDP 动画事件确认松手后没有重新播放 `arrive`，位置保存及展开仍正常。

Windows 通知使用 [Tauri 官方通知插件](https://v2.tauri.app/plugin/notification/)，由 Windows 通知中心负责展示；点击通知可返回主窗口。通知投递与横幅显示受 Windows 设置控制，未修改用户的全局通知开关或勿扰设置。

# SnowDown v0.2.12

增加 Windows 开机自启动。

- 首次安装默认勾选“开机自启动”，安装前可取消。与“安装完成后启动”独立控制。
- 覆盖升级保留原选择，包括在 Windows 启动应用中禁用的状态。
- 偏好设置 → 下载设置 → 开机自启动：读取系统真实状态，切换立即生效。
- 登录 Windows 后隐藏主窗口，在托盘后台运行；双击托盘图标或再次正常启动软件可显示窗口。
- 已开启自启动时，新版首次运行同步当前程序路径；卸载仅删除指向本安装目录的 SnowDown 启动项。
- 登录状态、下载内容、任务和原下载设置继续沿用。内置插件保持 v0.1.9。

免安装版默认关闭，可在设置中开启；移动软件目录后，正常运行一次更新启动路径。静默安装支持 /AUTOSTART=0 或 /AUTOSTART=1；未指定时首次安装开启、升级保留原状态。

SnowDown v0.1.1 · Windows

## 更新

- 改用B站官方二维码登录：手机B站扫码并确认，无需复制 Cookie。
- 登录状态由 Windows DPAPI 加密保存，重启自动恢复并验证；临时断网保留会话，退出账号删除本机凭据。B站会话失效后需重新扫码。
- 移除系统标题栏，将最小化、最大化/还原、关闭按钮融入软件顶部。顶部空白区域可拖动，双击可最大化。关闭窗口后下载在托盘继续，完全退出请使用托盘菜单。
- 安装器改为二次元异形窗口：透明立绘、冰蓝曲面面板、可编辑安装路径、进度与完成状态；保留升级、卸载与 WebView2 检查。正在运行的目标客户端会提示先退出，不会由安装器强制结束下载。

## 下载

- 安装版：`SnowDown_0.1.1_x64-setup.exe`。
- 免安装版：`SnowDown_0.1.1_Windows_x64_portable.zip`，完整解压后运行 `SnowDown.exe`，保留 `resources`。
- `SHA256SUMS.txt`：软件包校验值。
- `VERIFICATION.md`：测试结果及验证范围。

支持 Windows 10/11 x64。已包含 FFmpeg，系统需有 WebView2。异形安装器使用系统 .NET Framework 4.6.2+，不需额外安装 .NET Desktop Runtime。

在“设置 → B站账号”获取二维码。登录后的画质以账号当前权限和B站实际返回资源为准。

实际账号的扫码确认及其重启恢复需要用户用手机完成验收；开发验证使用官方未登录二维码接口和独立的加密会话测试，不使用真实账号凭据。

# SnowDown v0.2.16 验证记录

- 前端：23 个测试文件、159 项测试通过。
- Rust：88 项测试通过，6 项既有在线测试保持忽略。
- 两条用户提供的真实视频号分享链接通过官方会话解析并下载；验证记录不包含 Cookie、访问令牌或带签名媒体 URL。
- 样例 A：5.08 秒，1080×1448，H.264 视频和 AAC 音轨；音轨音量接近静音。样例 B：15.14 秒，576×848，H.264 视频和 AAC 音频，平均音量 -23.3 dB、峰值 -0.4 dB，确认不是静音。两份文件均通过完整音视频解码。

- 最终正式构建实际验证视频号 M4A 音频输出、音频解码及封面保存。会话从预览版迁移到正式版；原有 22 个任务、设置和其他平台账号文件保留。测试任务记录已移除，原下载内容保留。
- 定制安装器核心 35 项断言通过；实际嵌入 NSIS 负载的 28 个程序文件通过校验，内置插件版本为 v0.1.17。

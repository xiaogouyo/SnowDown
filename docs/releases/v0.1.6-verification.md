## 范围

真实联网测试覆盖当前 GitHub 正式版元数据与完整安装器下载校验；更高版本提示使用测试版本和模拟时钟验证。不会为测试创建虚假 GitHub Release。尚未在用户正式安装目录执行未来版本的完整原地升级；实际安装/重装/卸载和进程交接分别由隔离安装检查与核心测试验证。

应用内下载的是 Windows x64 安装器，由用户点击“退出并打开安装器”，再确认安装目录。免安装版若保持免安装方式，使用 GitHub ZIP 手动覆盖。暂缓提醒按版本保留 24 小时；启动及每 6 小时检查，手动检查不受暂缓影响。GitHub 限流、断网或下载速度较慢时可能需要重试。

新增检查不读取B站、抖音或小红书凭据。固定仓库、正式版本、附件名、大小与 GitHub SHA256 是本次更新包的校验依据；没有独立代码签名或额外更新签名机制。本次没有更改站点媒体解析及扫码登录实现。

上一版动画与 Logo 修复已经从误标的 v0.2.3 归档为 v0.2.2。重新构建了内部版本为 0.2.2 的安装版和免安装版，推送 v0.2.2 源码标签，并把原 GitHub Release 改为 v0.2.2、替换其附件。匿名公开 API 已确认其版本、文件名和下载地址均为 v0.2.2，五个附件摘要核对一致。旧的误标标签在检查其原始对象未变化后移除，原始源码仍保留在 Git 历史，原发布附件已在本机归档备份。

## 功能与回归

- 前端 88 项测试通过，TypeScript 和 Vite 生产构建通过。新增安装失败后的 ZIP 备用入口、取消保存不误报成功、重复导出保护、浏览器检测失败、写入错误，以及原生 Save 对话框与导出调用衔接的回归。
- Rust 68 项测试通过，5 项联网或速度基准测试默认忽略。新增 Windows 实际压缩与读回 ZIP：清单精确包含 11 项公开插件资源，manifest 位于根目录；不包含 Cookie、bindings.json 等账号或绑定文件。
- ZIP 生成使用内置插件资源，无网络下载。测试含中文、空格、单引号和美元符号的目标路径；路径通过环境变量传递，不拼入命令脚本。验证正常覆盖、临时文件清理，以及缺少资源时原 ZIP 字节不变。
- 安装面板移除旧步骤长列表、目录路径与两段说明；改为五步图标，详细提示仅在悬停或键盘聚焦时显示。保留 Chrome / Edge 检测和安装／管理入口。
- 根据界面反馈移除流程数字徽标，并加入卡片上浮、轻微放大和阴影过渡。真实 Chromium 测得约 60ms 的中间变换、最终上移 4px / 放大 1.04 倍，以及移开后恢复；提示透明度连续变化。键盘聚焦效果一致，减少动态效果时无位移，数字标数量为零。
- 在独立 Windows 应用标识和资料目录中，实际打开插件面板，检查 1180×820 与 960×660 窗口。修正末尾图标占位导致的横向溢出后，五个图标完整可见、无横向溢出，原生渲染截图与键盘提示检查通过。
- 在同一隔离客户端中通过真实 IPC 调用导出，成功写入并读回 ZIP 文件。未读取真实账号或下载媒体，也未修改用户浏览器注册表。界面保存取消和错误状态由前端回归覆盖。
- 从软件导出 ZIP 时，为已安装浏览器准备本机绑定，保留已有绑定标识和用户偏好；绑定失败不会阻断独立 ZIP 导出。绑定写入与现有自动安装串行，避免互相覆盖。

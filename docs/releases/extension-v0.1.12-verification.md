# 插件 v0.1.12 验证记录

日期：2026-10-26。桌面官方安装包保持 v0.2.13。

- 原始 v0.1.11 ZIP 在隔离 Chromium 的新旧 YouTube 封面夹具中均复现：雪花图标位于 `yt-image` 下，实际命中兄弟遮挡层，真实鼠标点击无法打开菜单。
- v0.1.12 同样夹具均命中按钮、展开对应视频菜单，不跳转原网页；隐藏内层图片后仍可点击。新增回归脚本为 `tests/youtube-click.browser.mjs`。
- 匿名访问真实公开 YouTube 搜索页，命中雪花按钮并以真实鼠标点击展开 Popover，页面未跳转。该验证仅确认线上点击入口；匿名首页没有推荐卡片，首页新旧结构通过夹具覆盖，未宣称线上全部视频下载通过。
- YouTube 预览回归通过：读取目标观看页、视频 ID 匹配、实际下载文件的视频和音频可解码，未将嵌入页当作媒体。
- 原生锚定回归通过：内层滚动、文档滚动、CSS 变换、顶栏遮挡、容器裁切、顶层菜单、滚动关闭、对话框点击、原内联样式还原。
- B站和抖音左上角位置均为 6px，图标内外中心偏差为 0；独立悬浮球仍已移除。
- 生命周期与 Logo 回归通过：严格图片 CSP、无页面扩展图片请求、原 PNG 像素、扩展重载清理、上下文失效停止旧脚本。
- 缓存竞态回归通过：无关元数据、统计 Cookie、其他平台认证不打断；真实认证变化仅重试一次；真实导航拒绝旧结果；失败菜单可重新读取。
- B站预览及下载回归通过：对应卡片标题、实际画质、音视频可解码；旧卡片、伪域名、缺少票据均拒绝。
- 142 项前端测试通过。

浏览器验证使用独立 Chromium 配置，测试副本禁用原生消息，不访问用户 Edge 账号或同步测试 Cookie。未重建或替换桌面安装包。

# SnowDown v0.2.17

接入已上架的 [SnowDown Chrome 商店版](https://chromewebstore.google.com/detail/snowdown/npedaeojbodmkfiaicobfdakidgafdim)，插件继续使用 v0.1.17。

- 桌面「浏览器插件」中的 Chrome 安装入口直接打开官方商店，无需开发者模式；未安装 Chrome 时仍提供浏览器下载。
- 原生消息通道同时允许商店正式 ID 和原 ZIP 版 ID，启动来源必须精确匹配，不向其他扩展或网页开放。
- 商店安装后首次连接自动建立本机绑定，插件原有桌面下载和账号同步偏好继续生效，可在插件设置调整。
- Chrome 商店版由浏览器管理更新；GitHub 检查和 ZIP 下载作为本地版更新、备用安装途径，不用 ZIP 覆盖商店版。
- 保留 Edge 本地安装及旧 ZIP 插件联动，不修改插件源码、权限或已发布 v0.1.17 安装包。

安装新版桌面后保持软件运行，在 Chrome 商店安装插件。首次安装后打开插件；若插件面板已打开，可关闭再打开等待连接。原账号、设置、下载记录和文件继续保留。

此版本只适配商店安装及联动，既有 Issue #1–#6 不在本次修复范围内。

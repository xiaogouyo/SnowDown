## 受控浏览器测试复现

先构建插件并准备本机 Playwright Chromium。测试读取 `SNOWDOWN_PLAYWRIGHT_PATH`，未设置时从本项目依赖解析 `playwright`。需要完整的 FFmpeg 组件；可以生成测试媒体：

```powershell
New-Item -ItemType Directory -Force .tools | Out-Null
& .\src-tauri\resources\ffmpeg.exe -y -f lavfi -i testsrc=size=320x180:rate=24 -f lavfi -i sine=frequency=440:sample_rate=44100 -t 2 -c:v libx264 -pix_fmt yuv420p -c:a aac .tools/v024-fixture.mp4
node scripts/build-extension.mjs
node tests/preview.browser.mjs
node tests/web-sites.browser.mjs
node tests/douyin.browser.mjs
node tests/extension-drag.browser.mjs
```

测试使用独立浏览器目录与受控网络响应，不读取用户浏览器资料。测试产物位于忽略的 `.tools` 目录，不随发布包分发。

站点目录与受控测试不等于所有实际网站均已下载成功，详见[平台范围](../platform-support.md)。

SnowDown v0.1.6 · GitHub 新版本提醒与下载更新

## 更新

- 右上角新增版本号入口，点击可查看当前版本、更新说明并手动检查更新；底部版本号也能打开更新面板。“关于”窗口原“开始收藏”按钮改为“检查更新”，点击关闭关于窗口并检查新版。
- 启动后及每 6 小时检查本项目的公开 GitHub 正式版，发现更高版本时弹窗提醒。自动检查失败保持安静，手动检查显示网络或请求限制提示，不会将检查失败误报为已是最新。
- 可选择“暂不更新”，同一版本 24 小时内不再自动弹窗，手动检查仍可查看并下载；遇到其他弹窗时等待其关闭再提醒。
- 支持软件内下载更新包、显示进度、后台下载、取消和失败重试。只接受本仓库中符合版本号的 Windows x64 安装器，核对 GitHub 提供的 SHA256 和文件大小，安装前再次校验。
- 下载并校验完成后，点击“退出并打开安装器”。有排队、下载或合并任务时需先暂停或完成。安装器等待原进程退出，预填当前软件目录，由用户确认安装。
- 更新检查无需 GitHub 登录，不读取平台账号凭据。预发布、草稿和较旧版本不会作为可用更新。

## 下载

- 安装版：`SnowDown_0.1.6_x64-setup.exe`。
- 免安装版：`SnowDown_0.1.6_Windows_x64_portable.zip`，完整解压后运行 `SnowDown.exe`，保留 `resources`。
- 附件提供 `SHA256SUMS.txt` 与 `VERIFICATION.md`。

v0.1.5 及更早版本尚无此更新入口，需先手动升级到 v0.1.6。以后发现更高正式版即可在软件内下载更新。应用内下载的是安装器；希望继续保持免安装方式的用户，可在 GitHub 下载 ZIP，退出后解压覆盖原目录。

需要 Windows 10/11 x64 与 WebView2。升级沿用任务、设置及平台登录资料。GitHub 连接和下载速度取决于网络，连接失败时可稍后重试或打开 GitHub 发布页。原有批量下载及三平台扫码功能继续保留。

# v0.2.13 / v0.1.10 验证记录

日期：2026-10-26。

- 前端 137 项测试通过，TypeScript 与 Vite 生产构建通过；Rust 83 项通过、6 项依赖外部环境测试未执行。
- 50 类共享平台的桌面与插件识别一致，Rust 逐项验证全部域名别名与伪域名拒绝。
- 真实隔离 Chromium MV3：原三平台预览/当前视频回归，47 类通用站点受控页面回归通过。通用站点测试在隔离清单中预授可选权限，不代表替用户授予真实浏览器权限。
- 视频含音频可实际解码，M4A 仅含音轨，HLS 视频及分离音轨合并可解码；伪域名、旧卡片、缺失票据拒绝。
- 图标原 Logo 像素、左上角定位、嵌套滚动及 CSS 变换、原有样式还原、扩展刷新清理旧上下文通过。并行浏览器布局截图曾遇浏览器退出，独立重跑布局验证通过。
- 真实 Worker 返回独立线程标识，确认同时运行 2 个 Worker；空闲 30 秒后释放并按需新建。缓存命中不增加 API 请求，登录 Cookie 改变后重新请求，手动重新解析跳过缓存。
- 1200 张视频卡片的受控页面中，访问及滚动不触发预解析 API 请求。无插件入口时最大帧间隔 6.2 ms，启用后 6.3 ms，两组均无超过 50 ms 的采样；这是单次 headless 回归，不是所有硬件和真实网站的性能保证。

- 真实桌面 v0.2.13 与插件 v0.1.10 原生握手、实际版本比较、内置版本展示、离线 ZIP 导出通过。原有任务 ID 与下载设置保持；本机恢复普通启动，关闭临时调试端口。

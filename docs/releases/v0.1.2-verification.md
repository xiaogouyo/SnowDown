# Windows v0.1.2 验证记录

日期：2026-10-24。构建环境：Windows x64，Node.js 24、Rust MSVC、Tauri 2。

## 已通过

- TypeScript 检查及 Vite 生产构建，Windows Release 原生程序与两层安装包构建。
- 前端 22 项测试：原有下载和官方二维码登录流程；三平台链接识别、追踪参数清理与必要分享参数保留；剪贴板聚焦提示、不覆盖正在编辑的链接、可选自动解析和关闭识别；一键粘贴解析；官方页面返回后的正确视频解析与编辑保护；统一下拉菜单的键盘、滚动与外部点击交互。
- Rust 26 项常规测试：原有输入、SQLite、断点续传、FFmpeg、B站认证；抖音数据、竖屏画质与分离音频，小红书编解码分组/备用媒体地址、图文拒绝；官方页面来源 ID 一致性、媒体域名与官方响应路径约束、旧数据兼容与平台会话隔离。
- 显式运行的 3 项联网测试：B站官方未登录二维码生成与等待状态；B站实际解析和 CDN 读取；完整下载、FFmpeg 合并及 ffprobe 音视频轨道检查。样例时长约 198.27 秒，下载视频流 5,338,110 字节与音频流 861,383 字节。
- 抖音原生程序完整下载：读取软件内官方窗口的视频详情响应，下载分离音视频并由同一下载组件合并。传输共 135,603,805 字节，最终 MP4 为 135,900,613 字节；ffprobe 确认约 444.173991 秒且含视频和音频轨道。
- 抖音窗口返回：使用另一条当前界面中的链接，自动关闭官方窗口，经实际窗口事件、会话保存、前端监听与原生解析，确认对应标题、画质选择和下载按钮均已出现；原生辅助功能文本再次核对。没有创建用户下载任务。
- Windows 当前用户 DPAPI 持久化：模拟B站凭据的覆盖、重新读取、损坏回退、退出清除和过期请求隔离；模拟抖音/小红书会话分别加密保存、重新读取与按平台清除。没有使用真实账号凭据执行这些测试。
- 浏览器界面预览检查：按原生默认 1180×820 与最小 960×660 尺寸检查长链接、统一下拉菜单、平台会话面板、设置滚动和固定保存区。截图位于 `docs/design/v0.1.2/`。这是前端布局验证，不代表原生窗口交互已全部验收。
- 异形安装器核心 12 项断言及内嵌负载校验；安装前、安装中、完成界面由实现代码离屏渲染并检查。
- 隔离安装器集成：独立 QA 产品名、注册表与工作区中文/空格路径；验证外层解包、安装、程序与 FFmpeg 哈希、版本登记、重装、实际阶段提示、卸载及无关用户文件保留。前端与 NSIS 后端均阻止覆盖正在运行的测试程序。
- 本机常用免安装目录已更新到 v0.1.2，启动程序与版本化发布目录中的原生程序 SHA256 一致。更新前确认本机没有下载任务，旧程序已备份。

## 样例与验证范围

用户提供的抖音精选视频链接可规范化为视频页；未登录请求未返回视频详情。小红书视频笔记在未登录环境下跳转官方登录页。必要分享参数仅保存在本机测试文件中，没有放入公开仓库或发布附件。

用户在本机 v0.1.2 中反馈B站、小红书正常，小红书本轮未做自动化完整下载验收。抖音已通过实际下载及官方窗口关闭返回检查。详情读取限于软件内官方窗口、指定视频详情路径与对应视频 ID，只短时保留视频元数据及媒体地址，不记录账号接口响应、网页正文或签名媒体地址。实际返回时确认会话文件已更新；账号会话长期有效性和重启恢复仍需人工验收。平台要求登录、验证或分享参数失效时，不能保证直接下载。仅支持视频，不支持图文、图集、直播、私密内容或合集。

Windows 原生剪贴板焦点事件和真实账号网页登录流程尚需人工验收。不同 DPI/多屏、休眠恢复、长期运行和全部账号画质未覆盖。B站凭据与新站网页会话的实际有效期均由平台决定。

构建时 NSIS 存在上游简体中文翻译键 `choowHowToInstall` 缺失提示；公共安装器使用自定义 WPF 界面，隔离安装、重装和卸载验证均已通过。

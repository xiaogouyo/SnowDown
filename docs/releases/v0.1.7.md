SnowDown v0.1.7 · 更新镜像自动测速与故障切换

## 更新

- 更新包下载前，实时检测完整的 66 个镜像地址，按本次实测延迟选择可用节点；旧表格中的延迟和状态不会作为固定结果。
- 并发检测当前安装器的少量内容，过滤超时、错误页面和文件信息不匹配的节点。更新弹窗显示检测进度、当前下载源与延迟，展开“镜像库”可查看全部节点状态。
- 镜像连接中断、下载失败或校验失败时，清理未完成文件并自动尝试下一个可用节点，最后回退 GitHub 官方直连。测速与下载均可取消、在后台继续或重试。
- 版本信息、安装器大小和 SHA256 继续直接从官方 GitHub 获取。镜像仅传输文件，完整校验通过后才允许打开安装器；不发送 GitHub 令牌或视频平台会话。
- 保留已有的新版提示、24 小时暂缓提醒、三平台扫码登录、批量下载和自定义安装界面。

## 下载

- 安装版：`SnowDown_0.1.7_x64-setup.exe`。
- 免安装版：`SnowDown_0.1.7_Windows_x64_portable.zip`，完整解压后运行 `SnowDown.exe`，保留 `resources`。
- 附件提供 `SHA256SUMS.txt` 与 `VERIFICATION.md`。

需要 Windows 10/11 x64 与 WebView2。v0.1.6 可在软件内下载本版；升级后下载后续版本时使用新的镜像策略。希望保持免安装方式的用户可下载 ZIP，退出后解压覆盖。

镜像是第三方服务，可用性取决于所在网络。即使所有镜像不可用，也会尝试官方地址；GitHub 版本检查仍需连接官方 API。已完整校验的本地缓存会直接复用。完整列表与检测说明见 [更新镜像库](https://github.com/xiaogouyo/SnowDown/blob/v0.1.7/docs/update-mirrors.md)。

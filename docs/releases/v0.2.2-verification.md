## 复现方式

常规前端：`npm test`、`npm run build`。原生：`cargo test --manifest-path src-tauri/Cargo.toml --lib --locked`。

真实浏览器回归：启动 `npm run dev -- --port 56969` 后，在具备 Playwright 的环境运行 `node tests/mode-morph.browser.mjs`；可通过 `SNOWDOWN_UI_URL` 指定页面地址、`SNOWDOWN_PLAYWRIGHT_PATH` 指定外部 Playwright 的 index.mjs。默认使用本机 56969 端口，将结果和画面保存到忽略目录 `.tools/v023-mode-ui`。

原生动画回归入口为 Debug 构建中的 `SNOWDOWN_MODE_MORPH_VERIFY`。使用独立应用标识与 WebView 资料，关闭剪贴板监听和浏览器原生通道注册；不操作真实账号、系统剪贴板或下载媒体。正式构建不包含此调试入口。

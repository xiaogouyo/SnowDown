SnowDown v0.2.6 · 抖音精选页解析修复

- 桌面端与内置插件 v0.1.3 同步修复抖音精选页读取失败：除详情接口外，捕获推荐列表、关联视频及合集的视频元数据，并严格匹配输入链接/当前弹层的视频 ID。
- 支持播放器附近 React 数据中的 camelCase 视频地址；页面已经开始播放或详情请求早于插件加载时，可从播放器的当前数据恢复视频详情。
- 桌面后台网页与插件共用详情提取逻辑；软件后台页面在导航前安装响应捕获，兼容 Fetch 的 URL 对象和 XHR JSON 响应。只观察官方视频元数据路由，不扩大浏览器权限。
- 不再缓存没有可用视频流的条目，避免不完整响应让后续解析持续失败；限制响应大小和遍历次数，保留当前视频校验及下载地址验证。
- 修复只有 H.264 / HEVC 备用地址时，插件错误报告没有视频的问题；已有悬浮球、拖动动画、系统通知、任务删除与续传功能保留。
- 识别抖音返回的验证码中间页，明确提示平台安全验证。此状态不等于账号登录失效；浏览器完成验证后，可使用插件读取并转发到桌面队列。

桌面版本 v0.2.6，浏览器插件版本 v0.1.3。安装包、免安装包和独立插件 ZIP 均提供；升级保留登录状态、设置、任务与已下载内容。插件文件更新后，请在 Chrome/Edge 扩展管理页刷新 SnowDown，并刷新原抖音页面。

用户已在 Edge 刷新 v0.1.3 后确认：原抖音样例能显示画质并下载。最终桌面版启动后，同一样例解析返回 4 档画质，原生队列下载得到 6,800,927 字节 MP4，画面与声音读取验证通过。官方要求安全验证时仍需先完成验证，软件不会绕过；详细验证见附件。

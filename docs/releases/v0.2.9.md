SnowDown v0.2.9 · 预览定位与抖音卡片修复

- 内置插件 v0.1.5，修复两个内容脚本压缩后的函数名冲突，避免播放器页面出现运行错误。
- 预览按钮缩为 30px，原 Logo 保持不变，增加半透明外框；展开菜单保持白底圆角。按钮跟随封面位置即时更新，移除滚动时的位置补间；支持网页内层滚动区，封面被裁切后隐藏按钮，避免悬空遮挡。
- 将新卡片扫描合并到空闲时段，滚动按动画帧只更新已有按钮位置；忽略自身界面变化，不再定时扫描整页。
- 补齐抖音无视频链接卡片、背景封面、个人主页投稿、搜索结果及未在地址栏携带视频 ID 的推荐／精选播放器。解析严格匹配对应视频，不依赖预先进入详情页。
- 抖音投稿与搜索响应只暂存投影后的视频字段，账号接口不采集。卡片切换后重新验证下载目标，旧菜单不能继续下载别的视频。

**更新方式：**桌面用户安装 v0.2.9；本机已经准备的插件目录更新后，需在 Edge / Chrome 扩展管理页刷新 SnowDown，再刷新已有网页。独立用户可下载 v0.1.5 插件 ZIP，替换原目录后刷新扩展。新版保留插件 ID、偏好、账号和桌面下载内容。

受控浏览器验证覆盖主页无链接卡片、背景封面、搜索响应、推荐／精选、嵌套滚动、旧卡片拒绝和实际音视频下载；同时回归 B站菜单及原有悬浮球功能。这些测试不等同于所有实际抖音页面均已验证，遇到平台验证或受保护内容仍会提示失败。

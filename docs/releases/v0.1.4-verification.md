# Windows v0.1.4 验证记录

日期：2026-10-24。Windows x64、Node.js 24、Rust MSVC、Tauri 2。

## 已通过

- 前端 34 项测试：三个平台分别验证官方过期状态和本地有效期到期自动获取新二维码；官方页面自行换码同步；面板关闭停止轮询、平台切换丢弃迟到结果；扫码状态与登录确认；已登录抖音/小红书只显示与B站相同的退出账号、检查登录，命令携带正确平台；登录确认不改变输入链接、不发起视频解析。既有下载、剪贴板、下拉菜单交互同时回归。
- 官方二维码提取检查：使用与官方页面相同的 DOM 结构验证二维码图片、过期与已扫码状态，排除无关头像、图片和输入值；登录入口加载后限次重试，不触发手机表单、短信验证码或安全验证。
- Rust 28 项常规测试：二维码只接受限长栅格图像数据；匿名或其他平台 Cookie 不会被视为账号确认。既有 DPAPI 持久化、账号隔离、来源 ID、媒体地址、SQLite、断点续传和 FFmpeg 检查通过。3 项历史显式联网测试本次保持忽略。
- 三平台真实二维码检查：B站官方接口、抖音及小红书官方页面均取得二维码并返回等待扫码；再次获取均得到不同二维码图片。抖音、小红书在隔离 QA 网页资料目录中检查，登录页面始终隐藏，没有打开官方验证窗口；没有扫描或确认测试二维码。
- 用户验收：在普通 v0.1.4 预览版中，由用户在手机完成扫码确认，并反馈抖音、小红书“两个平台都正常”，覆盖扫码后登录状态及“检查登录”结果。自动化未操作手机或验证码。
- 退出清理先停止页面并等待空白页加载完成，再调用 WebView2 独立资料清理接口；等待完成回调后清除该平台加密会话。最终隔离 QA 检查：抖音 Cookie 从 38 项清为 0 项，小红书从 14 项清为 0 项，预置测试 Cookie 均已移除。测试账号数据与网页资料分别位于专用 QA 目录，没有退出外部浏览器账号。
- TypeScript 检查、Vite 生产构建、Windows Release 原生程序和异形安装器构建通过。
- 安装器核心 12 项断言、内嵌负载校验通过；独立 QA 产品名与注册表、中文及空格目录验证安装、程序和 FFmpeg 哈希、版本登记、重装、运行中保护、卸载与无关用户文件保留。
- 本机常用免安装目录更新到本次正式构建；运行程序、版本化免安装目录与原生构建 SHA256 一致。更新前确认没有活动下载任务。
- 本机测试网页资料、登录二维码预览和私有分享参数均未纳入仓库或软件包；公开内容检查未发现 GitHub 凭据。

## 范围与限制

二维码自动过期处理使用加速时钟与模拟官方状态验证；真实网络检查覆盖获取、轮询等待和重新获取不同图片，没有等待三个平台的每种真实过期情形。抖音、小红书手机扫码确认及检查登录已由用户验收；重启后的长期会话有效性、全部账号和风控情形仍未全面覆盖。未扫描的隔离测试二维码只用于生成与换码检查。

成功状态要求官方页面显示账号入口，并取得对应平台账号 Cookie；随后持久化成功才通知界面。检查登录时网络失败保留账号，平台明确显示未登录则清除保存状态并要求重新扫码。平台验证码或风控要求会直接报告，不弹出官方验证窗口，也不自动处理验证。

本次未修改媒体下载和合并实现，未重复下载完整长视频。历史B站、抖音及小红书解析/媒体读取范围见 v0.1.2、v0.1.3 验证记录。平台页面结构变化、WebView2 版本及账号权限可能影响扫码和解析；不同 DPI、多屏及长期运行未全面覆盖。

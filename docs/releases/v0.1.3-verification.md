# Windows v0.1.3 验证记录

日期：2026-10-24。Windows x64、Node.js 24、Rust MSVC、Tauri 2。

## 已通过

- 前端 23 项测试，包括：登录返回不替换链接、不自动解析；空输入保持为空；登录保存失败提示；登录入口只传平台、不传视频链接；登录期间编辑内容保留；手动保存不重试解析或关闭设置；从登录窗口聚焦回来不读取剪贴板触发自动解析。原有下载选择、二维码状态、剪贴板与统一下拉交互同时回归。
- Rust 26 项常规测试通过，3 项显式联网测试本次保持忽略。视频 ID 隔离、可信媒体地址、分离音频、旧数据兼容、加密会话、断点续传与 FFmpeg 检查通过。
- 原生完整解析交互：分别以两条抖音链接冷启动调试程序，通过主界面输入框事件与表单提交调用真实原生解析；均未打开登录窗口，后台解析保持隐藏。确认输入链接不变、返回视频 ID 匹配、标题、画质和下载按钮出现，并实际读取视频流与音频流的首段字节。
- 同一路径验证用户提供的小红书视频链接：输入、提交、后台解析、对应视频展示及媒体首段读取均通过；没有在登录窗口打开目标视频或手动播放。
- 后台页面复用软件自己的平台资料目录，解析成功或超时后转为空白页，隐藏页面原生静音。正常解析过程中没有创建或显示官方登录窗口。
- TypeScript 与 Vite 生产构建、Windows Release 原生程序、自定义异形安装器构建通过。
- 安装器核心 12 项断言与内嵌负载检查通过。独立 QA 产品名、注册表、中文/空格目录下验证安装、版本登记、程序与 FFmpeg 哈希、重装、运行中保护、卸载与无关用户文件保留。
- 本机常用免安装目录更新到本次正式构建；运行程序、版本化免安装目录和原生构建的 SHA256 一致。更新前确认没有活动下载任务。
- 发布内容检查未发现本机样例的私有分享参数或 GitHub 凭据；测试资料与浏览器资料目录没有纳入仓库和软件包。

## 范围

本次真实媒体读取检查的是首段字节，没有重新下载完整长视频。v0.1.2 已验证的抖音约 444.17 秒有声音视频下载、FFmpeg 合并，以及B站完整下载链路见历史验证记录；本次没有改变下载传输及合并实现。小红书本次也未做完整下载验收。

官方登录、验证仍由用户在官方窗口完成，测试没有代替用户登录或处理验证码。软件保存的会话与平台自己的资料目录沿用上一版本；实际有效期和可用画质取决于平台与账号权限。长期运行、多屏/DPI、全部内容类型和账号画质尚未覆盖。

后台解析只读取与输入链接视频 ID 匹配的数据，不接收登录窗口当前播放视频作为来源。平台可能拒绝访问、要求登录或验证；此时由软件提示后在官方登录窗口处理，再手动点击解析。

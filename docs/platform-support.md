# 平台范围与使用方式

v0.2.13 / 插件 v0.1.10 统一下列 50 类目录及域名别名。插件按需使用最多 2 个 Worker、短期内存解析缓存及队列预算；导航、登录或播放内容变化会失效，支持手动重新解析。滚动中延后卡片发现，浏览列表不批量预解析；后台下载进度页不切走当前网页。更多平台权限仍由用户授予。

自 v0.2.8 桌面与 v0.1.4 插件开始共用 `shared/platforms.json`，v0.2.9 / v0.1.5 延续相同目录。目录参考 [DataTool 公开首页](https://www.datatool.vip/zh)和[公开问答](https://www.datatool.vip/downloader/faq/en)，不使用其专有插件代码。站点名称进入目录表示可以识别并尝试解析，不表示每一种页面、账号或媒体格式都可下载。

B站、抖音、小红书沿用专用解析和扫码账号管理。其余站点使用浏览器已加载媒体识别、页面预览链接读取及桌面独立 [yt-dlp](https://github.com/yt-dlp/yt-dlp) 解析。桌面与插件使用相同目录；无法从网页取得可下载媒体时，已连接的桌面端会尝试其对应提取器。部分平台需要先在浏览器登录、播放并允许站点访问。

插件设置中的“启用更多平台与预览下载”会请求可选网页权限，由用户在浏览器确认；默认只注入原有三平台。更新后刷新扩展及目标网页。插件可独立下载，也可在连接桌面 v0.2.8 后转交队列；旧桌面不支持的新任务自动回退浏览器。

## 验证与边界

- 已在真实网站验证 YouTube `Me at the zoo` 元数据、桌面实际下载并检查视频与声音；Archive 公开视频元数据解析成功。Vimeo 的一个公开样例要求登录，未计为下载成功。
- 47 个新增站点通过隔离浏览器中的受控页面验证，包括共享目录、当前页面媒体、原生消息转发、HLS 多画质与分离音轨、M4A 导出。此测试预设权限已经批准，不代表自动批准用户浏览器权限，也不等于这些网站全部完成实测。
- 原三平台中的抖音响应、React 播放数据、当前视频匹配继续执行浏览器回归；预览菜单验证卡片目标与下载票据，阻止过期卡片、伪域名及缺失票据请求。
- 普通媒体地址与签名链接仅用于本机任务；原有账号同步只涉及 B站、抖音和小红书。其余站点不批量导入 Cookie，不能保证需要额外授权的网页可以在桌面独立重现。
- 不提供 DRM 解密、验证码绕过、直播录制或付费访问权限。图集、私密页面、尚未请求的媒体、纯 blob / DASH 或平台改版可能无法处理。
- 原有下载内核的分段连接设置继续适用原三平台及更新文件；通用提取器的连接数用于其支持的分片并发，不能保证每个普通直链都开启同等数量连接。

构建时校验官方 yt-dlp 与 Deno 发布摘要；完整组件许可证随软件分发，来源记录见 `src-tauri/resources/extractor-build.json`。运行时不安装外部插件或远程组件。


## 桌面 v0.2.16：微信视频号

支持 `https://weixin.qq.com/sph/...` 分享链接，以及视频号官方预览详情链接。桌面通过用户在独立腾讯元宝官方窗口完成的登录会话解析链接，再向视频号官方接口获取可播放资源；不会读取外部浏览器或微信客户端账号数据库。会话由 Windows DPAPI 加密保存，可在平台账号 → 视频号中检查和退出。

首批处理普通可播放视频，使用现有下载队列、MP4/M4A 和封面保存。无视频地址、图集、直播或需要额外解密的响应不会作为成功解析结果。接口没有提供分辨率时显示“官方可用画质”，不虚构质量档位。源站可能不支持 Range；此时使用单连接并在继续任务时重新传输。视频号下载功能此次仅接入桌面，插件仍为 v0.1.17。

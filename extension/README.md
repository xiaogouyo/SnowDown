# SnowDown 浏览器插件 v0.1.12

支持 Google Chrome / Microsoft Edge（Chromium 116 或更新版本）。这是 Manifest V3 插件，可独立下载，也可连接 Windows 桌面版 SnowDown v0.2.13。

v0.1.12 修复 YouTube 封面下载图标被悬停预览层遮挡，按钮绑定稳定的外层封面；缩略图隐藏或替换后仍可点击，保留原 Logo、左上角位置和原生滚动裁切。桌面保持 v0.2.13。

v0.1.11 修复预览元数据、统计 Cookie 与原生连接波动造成的缓存误失效；真实登录变化按平台更新，稳定页面只自动重试一次，失败菜单支持重新读取。桌面保持 v0.2.13。

v0.1.10 新增最多 90 秒的内存解析缓存、相同请求合并、手动重新解析和最多 2 个独立 Worker。滚动时延后发现卡片，DOM 采集分片，账号同步不遍历视频状态；后台下载不切走当前网页。空闲 30 秒释放 Worker。使用本地 offscreen 权限，原有可选站点授权范围不变。[验证记录](../docs/releases/extension-v0.1.10-verification.md)。

v0.1.9 将所有平台的下载图标统一到封面或播放器左上角，移除抖音侧栏特殊定位；菜单沿左侧展开并约束窗口边界。其他解析、下载、账号与 Logo 保持原样。以下 v0.1.8 等段落为历史记录，以本段位置规则为准。

v0.1.8 保留 B站左上角，其他平台预览卡片右上角，抖音仅完整播放器使用右侧操作按钮中心对齐。YouTube 可读取目标观看页的实际直接媒体与已播放的同视频媒体；无法取得直链时尝试桌面解析，并设置明确超时。平台登录确认、签名或访问限制仍可能阻止下载，需要打开官方视频并播放后再读，不保证所有内容可下载。

v0.1.7 将原 PNG 在页面下载入口绘制为 Canvas，避免网页请求扩展图片地址被拒绝；原 Logo 像素不变。插件重载、上下文失效后停止旧脚本并清理控件。更新文件后必须刷新扩展，再刷新已打开网页；错误页保留的历史记录需单独清除。桌面 v0.2.10 原发布包仍内置 v0.1.6，使用本次独立插件 ZIP 更新。

v0.1.6 将预览按钮直接挂载在对应封面中，随网页滚动、容器裁切和 CSS 变换原生移动，不使用全局浮层跟随坐标。同一视频的不同卡片分别绑定按钮。菜单在浏览器顶层展开，页面滚动时收起回封面。保留原 Logo、30px 小图标和半透明外框。桌面 v0.2.10 内置同版本号的新修订，新增版本检测；以 v0.2.10 Release 的插件 ZIP 为准。独立悬浮球已移除，仅保留封面／播放器下载入口。B站入口位于左上角，抖音播放器入口位于右侧操作栏上方。

v0.1.4 保留原 Logo，新增视频和列表预览卡片旁的下载按钮，展开为紧凑圆角格式菜单。实际画质、M4A 音频和封面按资源情况展示。新增站点需在偏好设置点击“启用更多平台与预览下载”并确认浏览器权限，然后刷新网页；原三平台默认权限保留。共享目录包含 50 类站点，实际能力与验证边界见[平台说明](../docs/platform-support.md)。

v0.1.3 同步支持精选列表响应和已播放页面的 React 播放器数据，严格匹配当前视频。更新插件后请刷新原视频页面。

## 安装

推荐从桌面软件左侧“浏览器插件”贴片选择浏览器。软件会准备稳定的插件目录、注册当前用户的原生消息通道、打开扩展管理页与文件夹。开启开发者模式，选择“加载已解压的扩展”，选择软件显示的目录即可。首次连接默认启用桌面转发和账号同步，可在插件设置中关闭。

独立使用：下载 `SnowDown_BrowserExtension_0.1.12.zip` 并完整解压。在 `chrome://extensions` 或 `edge://extensions` 开启开发者模式，加载包含 `manifest.json` 的文件夹。固定工具栏 SnowDown 图标。更新已有插件时覆盖原文件夹并刷新扩展，再刷新已有网页。

普通 Windows 用户不能由软件静默安装未上架的扩展。当前未上架扩展商店，最后的浏览器加载确认需用户完成；不设置企业强制安装策略，不修改用户浏览器的 Preferences 或 Secure Preferences。官方说明：[Chrome](https://developer.chrome.com/docs/extensions/how-to/distribute/install-extensions)、[Edge](https://learn.microsoft.com/en-us/deployedge/microsoft-edge-manage-extensions-webstore)。

## 使用

当前 v0.1.6（桌面 v0.2.10 内置修订）已移除独立悬浮球。下列旧版功能记录仅供了解历史变化，当前使用封面和播放器下载入口，开关名称为“视频下载入口”。

v0.1.5 修复内容脚本函数冲突，预览按钮缩为 30px，增加半透明外框，滚动时即时锚定封面并遵守内层容器裁切。新卡片识别合并到空闲时段执行。抖音主页、搜索和推荐／精选均可读取没有视频超链接的卡片或播放器；仍以页面实际可用的视频详情为准。


v0.1.3 可拖动悬浮球到任意可见位置，也可拖动展开卡片的标题栏。刷新后会恢复保存位置，窗口缩放和在边缘展开时自动约束到可见区域。拖动不会触发展开，松手不会重播横向入场动画。关闭悬浮提醒时先收拢、缩小淡出；开启减少动态效果时直接关闭。弹窗和卡片采用细圆角滚动条。

v0.1.3 的“在新标签页打开”采用完整窗口布局，工具栏弹窗保留紧凑圆角界面。打开支持的视频页面并出现可见视频后，网页右侧会挤压弹出下载悬浮球；点击后球体展开为下载设置卡片，可选画质、跟随插件下载设置或本次使用浏览器下载。卡片可收起为球体。

在偏好设置关闭“视频悬浮球提醒”，或在卡片内点击“关闭悬浮提醒”，会隐藏已打开页面的提醒，并记住该选择。三平台默认注入，其他网页需要先在资源模式批准站点权限；已有页面可刷新后使用。不会在浏览器内部页面、未授权网页或没有可见视频时任意弹出提醒。

从桌面软件安装／更新解压目录后，请在浏览器扩展管理页刷新 SnowDown 插件，再刷新已有视频页。v0.1.3 保持原稳定插件 ID 和已保存的偏好。

打开B站、抖音或小红书的目标视频，点击插件图标，再点“读取当前视频”。浏览器中已有的账号会话直接用于解析。抖音和小红书需先播放视频，安装后的已有标签页可刷新一次，使插件观察到视频详情。选择画质后下载。

点击弹出界面左上角 SnowDown 标志或“网页资源”切换模式，首次需批准网页站点访问权限。可筛选视频、图像、音频、格式、最小宽高和地址关键词，再批量下载所选资源。滚动页面或播放媒体后刷新列表，可发现新加载资源。

未连接桌面端时使用浏览器下载。分离的 MP4 视频和音频在插件自己的下载页合并，下载期间保留该页；大文件建议使用桌面端。直接媒体交给浏览器下载列表。桌面端运行后显示“桌面已连接”，可在设置中切换桌面转发。软件离线时自动停用有效转发并回退浏览器，恢复后沿用用户偏好。需要软件时可从设置打开官方 GitHub 下载页。

普通 HTTPS 资源可交给桌面队列，使用断点与分段下载；本机地址、不支持的文件格式或跳转型资源可改用浏览器。网页资源列表仅包含已加载或已请求并可观察到的资源，不保证列出尚未播放、跨站受限、DRM 或私密媒体。播放清单和 blob 分段流不能作为普通 MP4 直接保存。当前不提供 DRM 解密、直播录制或小红书图集的平台解析。

## 账号与隐私

账号同步是可关闭的选项。仅读取B站、抖音和小红书的 Cookie，通过允许固定插件 ID 的原生消息通道同步到本机，桌面端使用 Windows DPAPI 加密保存。Cookie 不写入插件的 storage 或日志，不上传到 SnowDown 服务器；本地服务没有网页可访问的 HTTP 接口。其他站点的 Cookie 不会导入桌面端。

浏览器中未登录的平台不会清除桌面端已保存账号。插件获取的头像只来自对应账号控件；官方页面未提供头像时显示默认图标。资源和视频签名地址仅用于本机下载任务。网页资源读取权限与平台权限分开，可在浏览器中撤回。桌面软件关闭后插件仍可独立运行。

## 开发

在仓库根目录执行 `npm ci` 与 `node scripts/build-extension.mjs`。构建目录为 `src-tauri/resources/browser-extension`，不提交生成文件。`identity.json` 仅包含公钥和稳定插件 ID，不包含私钥；不要随意修改，以免破坏原生通道允许列表。浏览器合并使用 Mediabunny，完整许可证随包提供；源代码与锁定版本来自本仓库及其官方项目。

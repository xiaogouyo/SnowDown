# SnowDown

Windows 桌面视频下载工具，支持B站，并试验接入抖音、小红书视频。采用 Tauri 2、Vue 3、TypeScript 与 Rust，下载文件在本机处理和保存。

## 简约模式

点击左上角 SnowDown 标志进入简约模式，再次点击标志回到完整模式。v0.2.2 切换时，输入框连续移动、改变尺寸与圆角，下载按钮逐渐变为简约箭头，背景从实际点击位置圆形扩散；切回完整模式也有对应过渡，并记住上次使用的模式。开启系统“减少动态效果”时直接切换。

空闲时保留标志、窗口按钮和居中的圆角输入框。输入或粘贴支持的链接后自动识别解析，也可按 Enter 立即解析；输入框随动画缩小并移到顶部，下面直接显示视频信息、格式、画质、保存目录、附件和分P选择，以及下载队列进度。下载选择在页面内展开，可直接暂停、继续或定位文件。单次下载设置不改变全局偏好。

剪贴板识别遵守设置总开关。简约模式在前台识别链接后会自动解析；隐藏到托盘后是否自动解析，仍使用“识别后自动解析”设置。Ctrl+N 或输入框清除按钮可重新开始，切换模式沿用当前解析结果和原生下载队列。

## 功能

- BV号、av号、B站视频链接与 b23.tv 分享链接解析。
- 抖音视频页、精选页 modal_id、分享短链接；小红书视频笔记与分享短链接。可粘贴完整分享文字，自动识别平台并保留必要的访问参数。
- 原生后台监听剪贴板变化，缩到托盘后仍识别三平台视频链接。开启自动解析后在后台准备最新结果，回到窗口展示；保留手动编辑的链接，忙碌时延后展示，不自动创建下载任务。可在设置关闭识别。点击“粘贴并解析”或 Ctrl+Shift+V 仍可主动解析。
- 多P选择、当前账号可用画质选择、批量任务。
- “批量下载”或 Ctrl+N 打开多链接弹窗，支持三平台混合链接、完整分享文字，按换行、空格或逗号分隔并自动去重，每批最多 100 个链接 / 1000 个分P任务。
- 批量统一设置 MP4/M4A、画质上限、保存目录、封面/弹幕/字幕、全部分P及 0 至 3600 秒的同批任务启动间隔；设置仅用于本批。解析失败的链接保留重试，成功项一键入队，已有活跃任务自动跳过。
- MP4 视频与 M4A 音频，FFmpeg 自动处理。
- 下载队列、1至4任务并发、单任务限速、暂停/继续、失败重试。视频与版本更新共用分段下载内核，默认每文件8连接，可在设置中选择1/2/4/8/16连接；保存每段进度，暂停、断网或重开后可继续。
- SQLite 保存设置与任务；退出后再次打开，可手动继续中断任务。
- 可选保存封面、XML弹幕、SRT字幕；附加资源不可用不影响已下载的视频。
- 系统托盘、单实例、打开下载目录与定位文件。托盘右键使用与主界面一致的浅色圆角菜单，支持键盘导航、Esc 和失焦关闭，按屏幕工作区域定位。
- GitHub 新版本提醒：启动后和每 6 小时检查正式版，发现新版时弹窗；右上角版本号可随时手动检查。支持暂不更新（同一版本 24 小时内不再自动提醒）、软件内下载、进度显示、暂停/续传和后台下载。更新任务由原生端独立持有，“后台下载”仅收起面板；右上角显示进度，重新打开从原生状态恢复，校验成功后提供右下角提示，点击后自动覆盖安装并重启。
- 更新包下载前实时检测 [全部66个镜像](docs/update-mirrors.md)，选择延迟最低的可用节点；失败自动切换并最终尝试 GitHub 官方直连，完整校验官方 SHA256 后保存。更新弹窗可查看节点检测状态、延迟与下载源。
- B站官方二维码登录，在手机B站确认；Windows DPAPI 加密保存会话，重启自动恢复，退出账号清除本机凭据。
- 三个平台统一在软件内扫码登录；抖音、小红书二维码取自官方登录页，B站使用官方二维码接口。二维码过期自动更新，登录成功后加密保存，已登录时统一提供“退出账号”“检查登录”。抖音支持分离音视频流合并。
- 状态、画质、并发数统一使用软件内的下拉菜单；长链接不会挤压操作按钮，设置操作区保持可见。
- 与顶部栏融为一体的窗口按钮，支持拖动、双击最大化与关闭到托盘。
- 二次元异形安装界面，透明立绘、曲面面板、安装路径选择与真实安装阶段提示。

浏览器扩展已提供 v0.1.3；Linux和鸿蒙桌面客户端尚未实现。界面组件和站点解析/任务模块已分离，方便后续适配。

分段下载会验证服务器的 Range、文件长度与资源标识，并核对已保存分段的本地摘要。更新包还会校验官方 SHA256；同一版本可跨镜像续传。服务器不支持安全分段或资源发生变化时会重新下载，避免拼接错误文件。多连接有助于利用带宽，实际速度取决于网络和站点限制。单任务限速由所有连接共同遵守。

v0.2.1 修复小红书检查登录误清会话：检查不会主动打开扫码窗口，二维码过期、验证提示或网络问题只会提示暂时无法确认，并保留已有账号。检查前会恢复网页中缺失的保存 Cookie，不覆盖更新值。旧版已清除的记录如无法从网页恢复，需要重新扫码或由浏览器插件同步一次。

## 浏览器插件

独立插件 v0.1.3 修复抖音精选页读取，支持自由拖动悬浮球和卡片标题栏、保存位置、边界约束、关闭提醒的退出动画，以及细圆角滚动条。桌面 v0.2.7 已内置 v0.1.3，也可从上方插件 ZIP 单独更新。

桌面 v0.2.4 曾内置插件 v0.1.1：新标签页适配完整窗口，新增右侧视频悬浮球和原位展开的下载设置卡片。提醒可在插件设置关闭；三平台默认支持，其他网页需授权。插件更新后在扩展管理页刷新一次，已有视频页面也可刷新。

桌面端左侧新增插件贴片，可检测 Chrome / Edge、准备插件目录并绑定；插件独立版本为 v0.1.3。浏览器首次需开启开发者模式并确认“加载已解压的扩展”，当前未上架商店，不能静默安装。详细的安装、权限、独立下载、桌面联动与隐私说明见 [插件使用说明](extension/README.md)。软件离线时插件自动回退浏览器下载，重新打开后恢复连接。

v0.2.3 可在插件面板直接“下载 ZIP”，从内置资源离线生成本地安装包；联动安装失败也可使用。解压后在浏览器扩展管理页加载包含 manifest.json 的文件夹。安装教学改为五步图标流程，悬停或键盘聚焦图标可查看提示。上一版动画更新已统一归档为 v0.2.2；此前安装过误标 v0.2.3 动画版的用户，需要手动覆盖安装新 v0.2.3 一次。

更新下载并校验后会在右下角提示；点击“安装更新”会保存进度、自动覆盖安装并重启。只清理更新包、缓存和文件清单中的旧程序文件，登录、下载、任务和设置保留。抖音、小红书账号头像可在登录、检查登录或浏览器同步时读取。

## 使用

安装 `release/` 中的 Windows 安装程序，启动 SnowDown，粘贴视频链接并点击“解析视频”，选择分P与格式后下载。

也可解压免安装压缩包，双击文件夹中的 `SnowDown.exe`；请保留旁边的 `resources` 文件夹。

检查更新：点击右上角版本号，或打开“关于 → 检查更新”，查看当前版本、更新说明并检查新版。更新信息来自本项目的公开 GitHub Release，无需 GitHub 登录。自动检查失败时保持安静，手动检查会显示错误。选择“暂不更新”后，同一版本 24 小时内不再自动弹窗，手动检查仍可用；正在操作其他弹窗时，新版本提示会等待其关闭。

下载更新：点击“下载更新”，先实时检测66个镜像，按本次延迟选择可用节点，失败依次切换，最后尝试GitHub官方直连；已有完整校验的本地缓存则直接复用。可展开“镜像库”查看节点结果，可暂停并保存进度、重试或在后台下载，重开软件后仍可继续。下载完成并核对 GitHub 提供的 SHA256 与文件大小后，可点击“安装更新”，自动保存下载进度、退出、覆盖当前目录并重启，任务、设置和账号数据沿用。免安装版用户若要继续保持免安装方式，可在 GitHub 下载 ZIP，退出程序后解压覆盖原文件夹。v0.1.5 及更早版本尚无此更新入口，需先手动升级一次。

批量下载：点击右上角“批量下载”（Ctrl+N），粘贴多个视频链接或分享文字，统一设置后点击“一键下载”。成功项会加入队列，失败项保留在弹窗中。画质上限优先选择实际可用的较低画质，无较低档时选最低可用画质；竖屏按短边分辨率比较。默认只下载链接指定的分P，可勾选下载全部分P。间隔从同批上一个任务实际启动时计算，并遵守全局并发数；0 秒表示不额外等待。间隔随任务保存，重启后仍需手动继续中断任务。

默认目录为系统 Downloads 下的 `SnowDown`。关闭主窗口会隐藏到系统托盘，下载继续；完全退出请使用托盘菜单。临时下载保存在所选目录的 `.snowdown/<任务ID>` 中，成功后清理该任务的临时文件。移除任务记录不会删除下载文件。

登录：打开“设置 → 平台账号 → B站”，获取官方二维码，使用手机B站扫描并确认。凭据只由 Rust 后端接收，不返回网页界面；加密文件位于当前用户应用数据目录 `app.snowdown.desktop/bilibili-session.dat`，仅当前 Windows 用户可解密。启动时验证会话，临时断网会保留登录状态；B站会话失效后提示重新扫码。

抖音、小红书登录：在“设置 → 平台账号”选择平台，点击“获取登录二维码”，用对应手机 App 扫码并确认。二维码过期时自动重新获取；切换平台或关闭设置后停止轮询。账号确认后加密保存，输入视频链接并点击“解析视频”才解析下载来源。已登录界面与B站一致，可检查状态或退出账号。退出会清除软件内该平台的加密会话及独立网页资料，不影响外部浏览器账号。

二维码与后台解析使用软件自己的平台资料目录 `official-profiles/<平台>`，导入会话位于 `site-sessions/<平台>.dat`。此扫码流程不会读取外部浏览器账号；浏览器插件开启账号同步时，只同步三平台已授权的浏览器会话。平台要求安全验证时会提示稍后重试；软件不再打开独立官方验证窗口。会话有有效期，限制访问的内容不能保证可下载。

启用识别后，由原生后台检查 Windows 剪贴板变化；临时占用时自动重试，软件隐藏或最小化不影响监听。关闭识别后停止自动读取并取消后台解析。仅保留最新识别到的视频链接及解析结果，放在内存中，不保存其他剪贴板内容；不会记录剪贴板历史。连续复制新链接会取消旧解析，旧结果不能覆盖新链接。开启自动解析时在后台准备结果，回到窗口且没有其他弹窗时展示；保留手动编辑的输入，点击“查看结果”可使用缓存。失败可手动重试或重新复制链接，不自动创建下载任务。必要的分享访问参数保留在本机任务来源中，界面摘要不显示这些参数。

## 开发

需要 Node.js 22.12+、Rust stable MSVC、Visual Studio C++桌面工具与 WebView2。

```powershell
npm install
npm run setup:media
npm run desktop:dev
```

`npm run dev` 仅预览界面，解析与下载功能必须在桌面客户端运行。

```powershell
npm run build
npm test
cargo test --manifest-path src-tauri/Cargo.toml
npm run desktop:build
```

异形安装程序位于 `src-tauri/target/release/bundle/snowdown/`，内部 NSIS 负载位于 `bundle/nsis/`。构建时将 FFmpeg 及许可证一并放入安装包；ffprobe 仅供开发验证使用。安装器使用 Windows .NET Framework 4.6.2+，通常已随 Windows 10/11 安装，不需要额外安装 .NET Desktop Runtime。安装器构建和隔离测试说明见 [installer/README.md](installer/README.md)。

## 实现边界

- 清晰度由B站返回的实际可用流决定。扫码登录后重新解析，可更新当前账号可用画质。登录会话受B站有效期和风控限制，客户端不会绕过权限或承诺永久有效。
- 首版优先选择 AVC 视频与普通音频流；音频输出为 M4A，尚未提供MP3转码。
- 字幕和弹幕取决于源站可用性；XML为接口返回的弹幕快照，不保证完整历史弹幕。
- 页面暂不支持番剧、直播、收藏夹和UP主投稿列表链接。
- 抖音、小红书首批仅支持视频，不支持图集、图文、合集和私密内容。平台可能要求登录、验证或有效的分享参数。B站和抖音样例已实际下载并验证音视频轨道，小红书由用户反馈正常；具体范围见 Release 附件。网站数据结构变化可能影响解析。
- 暂停发生在媒体下载阶段；合并阶段可取消。应用重启后中断任务保持暂停，用户继续后重新解析资源地址并校验断点。
- 本机消息命令与下载核心分离；尚未注册浏览器 Native Messaging host。
